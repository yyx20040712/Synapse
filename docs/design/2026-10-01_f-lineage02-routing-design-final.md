## §1 自动走线实施面（案册零修改转入）

  面带检测也失败贴边+onWarn（数值退化，lane=−1）。

## §2 手动调线设计（PPT 式调节点位——增量对抗审闭合版）

### 2.1 数据模型与不变量

- `LineageEdge` 增可选字段 `via?: Array<{ x: number; y: number }>`
  （**内容坐标**中间路点，有序）。**序列化口径**（N-1）：缺省=省略字段
  （undefined），**不产出 `[]`**——空数组与缺省同义=自动路由，diff/脏检
  测零噪声。shared schema 变更+[locked-change] 随实施批。
- 端点**不进** via：fromNode+源锚点 id / toNode+目标锚点 id（12 锚体系）
  ——端点拖拽=重连（§2.3-6），交互域属 F-LGRAPH-01 ④。
- **via 不变量**（W-1 闭合，序列化时校验+编辑代数保证）：
  ①整条折线（锚 A→via…→锚 B）恒正交——相邻段轴对齐；
  ②无重合点——相邻路点距离 ≥1px；
  ③via.length≥1 才构成 manual-override（=0/缺省即自动）；
  ④端点变更（重连/卡移动锚变）时 via 保留，首/末段按新锚点局部重正交
  （L 重建，§2.3-6 同式）。
- **坐标锚定语义**（PPT 同款）：via=绝对内容坐标，端点随卡锚跟随；
  卡片移动/布局重排后 via 原样保留（不跟随），可能穿卡→§2.3-8 警示
  覆盖，「重置走线」一键回自动。
- **卡删除/图切换**（W-2 闭合）：卡删除→边随端点级联删除（现行边语义，
  via 随边消失，无悬空）；via 坐标系=**所属图的内容坐标**（每图自有边
  集），图切换/多图无迁移面。

### 2.2 渲染统一

- via 在场 ⇒ RoutedPath 由「锚点 A→via…→锚点 B」折线构造，route=
  `manual-override`；**甲圆角化 pass 照常应用**——pass 为**纯渲染层，
  永不回写 via**（B-2 闭合：共线顶点剔除=渲染期视觉省略，数据面手放
  顶点/手柄完整保留——加点未拖开时手柄照常可见）。
- **圆角化边界表**（W-5 闭合）：两顶点距 <2r ⇒ r_i=min(r, 段长/2, 2)
  逐顶点钳制（现行式含 t=2 最小直段）；180° 折返顶点（u=−v）=**不圆角
  渲染尖角**；连续短段按序逐顶点独立钳制。
- manual-override 边**不参与车道分组与避让链**（用户排位主权，不重算）；
  **命中优先级**（W-4 闭合）：手动边命中层挂 DOM 末位（视觉/命中均最上
  ）——手动横段与自动边同带重叠时选中/拖拽恒先命中手动边。
- **车道共存注记**：自动边共道分组仅收自动边（手动边不入组）——手动边
  占位后同带自动边不重排（接受视觉重叠，警示与选中态可辨）。

### 2.3 编辑代数（保持横平竖直——PPT 折线连接符同族）

1. **拖顶点**（W-6 精确化）：被拖点落点 P，**逐段独立判定**——入段竖直
   ⇒ 前邻.x←P.x；入段水平 ⇒ 前邻.y←P.y；出段竖直 ⇒ 后邻.x←P.x；
   出段水平 ⇒ 后邻.y←P.y（首末拐点联动止于短桩：锚点端被动、短桩沿
   法线伸缩）。
2. **拖段中**（增强项）：整段平移=两端拐点**绝对位移**同量（W-7：无隐
   藏状态，后续操作基于最新位置）；相邻段伸缩；**源/目标短桩段均不参
   与**平移。
3. **加点**：段上双击或右键「添加顶点」→段中点插入同向点（初始共线，
   渲染无差异、数据与手柄在场），拖开成拐。
4. **删点**（B-1 闭合，两类分治）：
   - 共线中点（加点未拖开态）→ 直接移除，无几何变化；
   - 真拐点 → **邻点 L 形重连**：入段轴保持（入横 ⇒ 新拐=(后邻.x,
     前邻.y)；入竖 ⇒ 新拐=(前邻.x, 后邻.y)）替换被删点，重连后新产生
     的共线邻点顺带消除；via 删空 ⇒ 回自动路由。
5. **重置走线**：线右键「重置走线」⇒清空 via 回自动路由。
6. **端点重连代数**（W-10 闭合）：拖端点=改锚（同卡 12 锚内换位或跨卡
   换端）——中间 via 全保留，首/末段按新锚点 L 重正交（新锚→第一 via：
   入轴=新锚短桩法线方向）+短桩重建；端点手柄与首拐点手柄不同形态
   （圆 vs 方）消冲突。
7. **通道磁吸**（拟推·可关）：拖动中顶点/段对通道中线 ±6px 磁吸——
   **优先级**（N-2）：先横通道（行隙/框间带中线）后竖通道（列缝中线），
   并列取距离最近者。
8. **INV-79 修订（两分句，呈裁点）**：自动路由=永不穿卡月标注（硬保证
   不变）；手动调线=用户主权，穿卡/穿标注**仅拖动中+选中态**警示渲染
   （W-8：警示色高亮非永久闪烁；渲染期重算零持久化——保存不阻断不
   标记、重载后非选中态不重现；穿卡检测口径同 PAD=4；e2e=自动面硬断言
   不变+手动面 data-attr 软断言）。若用户要硬禁（回弹式）一句话切换
   ——属呈裁点先裁后扩（N-5）。
9. **撤销与保存**（W-3 闭合）：撤销栈=会话内**逐单元 via 快照**——单次
   拖放（pointerdown→up，含全部联动子步与磁吸落点=N-3）=一单元；加/
   删点/重置/端点重连=各一单元；**保存=快照落库即撤销栈基线重置**
   （Word 式：保存后不可再撤回保存前；重开编辑会话自库态起栈）。
   via 序列化随边（编辑会话暂存+点保存批量落库=v97 定案）。

### 2.4 交互归宿
