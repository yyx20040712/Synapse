## 一、用户三条需求（原意，2026-09-26 口述转写）

1. **允许三种风格切换**：
   - 白天模式 = **精密仪表**（v1 四稿之 C 方向：冷灰白+靛蓝+信号橙）；
   - 夜间模式 = **黑色或深灰色背景**（新暗色 token，用户口述「黑色或者深灰色背景吧」）；
   - 护眼模式 = **牛皮纸**（v1 四稿之 D 方向：牛皮纸+索引卡+印泥章语汇）。
2. **侧边栏参考 B 站截图**：左侧面板由上至下依次为——**Synapse 标识、课题、下载、文献库、阅读器、脉络、设置**；同时**大幅缩小默认占地面积**（现行 178px 墨青宽栏 → 参考 B 站 ≈80px 图标窄轨：图标上置+小字标签下置、选中=主题色、底部贴底工具、无分割线靠留白分区）。
3. **脉络图重设计**：从上至下为**按 年+月 分布的时间线**；每个月份一个**符合当前主题风格颜色的虚线框**把该月所有文献框起来；**拖动文献会改变所在月份框的高度**；**拖动要有动画**。

## 三、待用户确认清单（2026-09-26 第二轮已全部裁毕，答案如下）

- **A1（原Q1）时间线方向**：✅ **旧→新**（2019 在顶，现稿方向保留）。
- **A2（原Q2）月框内排列**：✅ **横排交错排列**——2026-09-26 口径修正：指**同一月框内卡片换行后，上下两行横向错位半卡（砖砌式），使脉络线从行间空隙穿过、互不遮挡**；非「同一行内上下不齐」。
- **A3（新增）**：✅ **出编辑模式**（改月/改线型/新建连线的显式模式，见 A12/A14）。
- **A4（原Q4）空月框**：✅ **保留**（空框+拖入提示）。
- **A5（原Q5）侧栏**：✅ **72px 固定现稿**（不 hover 展开）。
- **A6（原Q6）主题切换入口**：✅ **设置页**（顶栏不放主题钮）。
- **A7（原Q7）夜间**：✅ **深灰 #14161A** + **PDF 纸页反色**（暗纸面呈现）。
- **A8（原Q8）「下载」语义**：✅ **文献搜索与下载引擎**——规划中未实现（导航占位，不挂任务角标）。
- **A9（原Q9）卡片**：✅ **要核心想法摘要行**，且卡片改 **长宽均减半**、**背景更深** 的小卡（208×~104 → 104×~52）。
- **A10（原Q10）课题**：✅ 点击 → **课题选择列表**；选中后 **侧栏图标与说明文字随之变化**（标签=课题短名）。
- **A11（新增）**：✅ **加大月框间距**，跨文献连线 **不得穿任何月框**（走框间空隙/绕行走廊）。
- **A12（新增）拖拽语义修订**：✅ 拖动卡片 **只能与本月份内其他文献调换位置**，**不能跨月调换**（改月走编辑模式，见 A3）。
- **A13（新增）连线走向**：✅ **上下连接（父子）或平级连接（水平弧）**，**不做左侧沟槽全出线**。
- **A14（新增）线型子系统（CAD 式）**：✅ 每个基础线型下可 **新建子线型**（独立颜色/线型），**随时可换**——区分不同解决问题的方向。
- **A15（新增）顶栏/侧栏顶部**：✅ 取消左上角菱形图标；顶栏最左 **Synapse 艺术字签名**（bilibili 式，垂直居中）；**全局搜索水平居中**。

## 三·B 第四轮补裁（2026-09-26 第三批口述）

- **B1 拖拽候选位**：拖动文件时候选位置=**两行交错排布的文献位**（槽位实时预览式重排，取代「与卡互换」语义；「两行交错」口径同 A2 修正=砖砌行错位）。
- **B2 线型选择器**：改为**点击展开后选择**（基础型分组▸子线型▸组内新建）。
- **B3 连线避让**：连线**不得穿过任何文献卡或月份标注**（被挡则自动改走绕行/调整入口）。
- **B4 定稿范围（重要）**：本轮先做「**自动化 + 人工笔记 + 人工绘制脉络**」；核心要求=**全部数据结构化、易被 AI 阅读**；随后**定稿开始设计**，目标=**美观 UI + 人工部分业务逻辑完善**。**AI 部分与下载模块后置**（后续再制作或大改——检查面板 AI 分节已标「后置」、下载已标「规划中」）。
