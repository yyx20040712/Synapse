## 2. 网格模型

### 2.1 步长与坐标口径

- **步长 P=8px**（与现行 SLOT_L_MIN=8 同值；取代 s=6/9 双值）。平行线间距
  承诺：**分配结果中任意两条非豁免平行段间距 ≥8px**——由分配规则保证
  （§3.3），非由生成坐标保证（偶/奇相位格位互差 4px，见 §2.5-④；审查
  B3 更正：v1「生成结构保证」不成立）。
- 车道=坐标常量线（竖道 x 常量、横道 y 常量），配逐段生死区间（§2.2）。
  坐标在内容 own 域，QUANT=0.1 量化沿承。
- 车道域（裁决③「不超月份框左右边界」按框 border-box 口径，审查 B2 更正：
  v1 收紧到内容盒致左锚桩出界）：x ∈ [框左内缘, 框右内缘]（各帧同宽同位，
  全图合并为单一 x 域）；y ∈ [0, contentH]（内容盒全域，含框间隙/年份区/
  首上末下外区带）。**左右框外走廊结构性不存在**（现行 outer-ring 左环
  消失，绕行改经上/下外区带与框间走廊，见 §2.5-⑤）。

### 2.2 死区与端点豁免

障碍集单源沿承 `allObstacles`=实卡∪月标注∪年份头（空卡位区非障碍沿承）。
障碍按 **DEAD=6px**（=avoid.PAD，线-卡净距常量沿承）膨胀后与车道求交，
相交区间为死段。**端点豁免沿承现行终门口径**（审查 B1 补：v1 漏写致锚点
自锁）：本边源/目标卡的死区豁免仅限首/末桩段（外法线 10px 内）；第三方
卡/月标/年份头永不豁免。车道图构建、搜索可行性、finalize 终门消费同一
谓词（avoid.ts polylineClearStubs 单源沿承）。

### 2.3 车道族生成（仅由布局派生，横竖同构）

统一锚定公式：**车道坐标=走廊锚定边（未膨胀）±(10+8k)**，k=0,1,…
（首道离卡 10px=现行 SLOT_STUB 口径；与错峰桩端同格，审查 B4 修复）。
四族产物并入一张全局车道表（量化坐标去重，全序枚举）：

1. **锚道**：每卡 top/bottom 锚 x（卡左+32/64/96）入竖道；left/right 锚
   y（卡顶+18/36/54）入横道。承载桩、直连（同列竖直/同排同高水平 0 拐）
   与行内短横移。
2. **间隙道**：逐相邻卡对开间隙（未膨胀边距 72px 的行隙/列隙，含偶/奇
   相位列隙 [140,212]+200k / [240,312]+200k 帧内容相对系）：车道自
   `边+10+8k` 生成至 `对边−10`。72px 隙 → 7 道（+10,18,…,58）。
3. **边侧道**（审查 B2 补，承接现行 detour 左右边侧通道职能）：框左缘带
   车道 x=首卡左−10−8k（≥框左内缘止——首列卡左=内容左 12 → 仅 x=2 一道）；
   框右缘带对称（末卡右+10+8k ≤ 框右内缘）。边侧道全高存活（月标/年份头
   文本矩形按死区杀段），是背向钉锚掉头与单卡列绕行的承载道。
4. **外区带**（审查 M1 补，承接 outer-ring 上/下外圈职能）：上外区
   y=首障碍上缘−10−8k（≥0 止）；下外区 y=末障碍下缘+10+8k（≤contentH−10
   止）。**退化防御**：障碍集空或 contentH 非有限/不足 → 外区带为空集
   （空图无卡即无边可路由，端点缺失防御早退承接——不产生无锚定边外区）。
   contentH 入 LayoutSnapshot 新增字段（B2 契约变更，§9）。

供给量（按冲突团口径，§3.3 规则下 ≥8 独立集）：行隙 7 道+锚道 3；列隙
候选=本相位 7 道+异相位锚道（144/176/208 帧相对系与偶隙道 150…198 相邻
至 2-6px），按 ≥8 独立取用后每隙可用 ≈7 道。R2-C5 压力样本（单月 20 卡
36 边）单隙并行峰值约 9 道：7 道内消化，超出按裁决④叠加（§3.4）。

**确定性**：车道生成纯函数，全序枚举（族类→坐标升序），无随机/无 Date/
无三角函数沿承。

### 2.4 网格更新触发

车道表仅依赖布局（cards/labels/yearHeads/frames/contentW/contentH）。
边集/端点/via 变化不重建车道表（裁决②）。布局变化（卡增删移、W 变、
uiScale 档变、月分组变）→ 车道表整体重建（纯函数，重建成本≪分配成本）。

### 2.5 手推算例（帧 padding-box 相对系=border 内缘起算，同 capacity.ts
hitTest 口径；帧 padding 18/12、卡 128×72、节距 200×144、错位 100——
审查 B1/B2/B4 要求的可达性证明）

- **① 四侧锚桩**：卡 A {x:12,y:18,w:128,h:72}。bottom 锚 (76,90)：桩段
  (76,90)→(76,100) 落锚道 x=76，前 10px 豁免自卡死区（自卡膨胀下缘 96，
  90..96 豁免、96..100 桩余段已在死区外）；100=行隙首道（90+10）可转弯。
  right 锚 (140,54)：桩 (140,54)→(150,54) 落锚道 y=54；左向 left 锚
  (12,36)：桩至 (2,36)，x=2=框左边侧道 ✓ 在框内。四侧均有道可转。
- **② 背向钉锚掉头（单卡列）**：源卡钉 bottom 锚、目标在其正上方（上一
  行/上一帧）。路径：(76,90)↓(76,100)→左 (2,100)↑(2,目标带)→右（目标
  锚道 x）→入目标 top 锚。x=2 边侧道在自卡 y 跨度内存活（|2−12|=10≥6），
  掉头成立。
- **③ 奇偶跨行阶梯**：偶行隙道 x∈{150,…,198}+200k、奇行隙道
  x∈{250,…,298}+200k，x 域不交——长竖线跨奇偶行必走阶梯（1 次横移/行）。
  这是砖砌布局的几何必然（现行 band 阶梯同语义），金标纳入阶梯形态。
- **④ 跨相位 4px 冲突**：偶隙道 174 与奇锚道 176 相距 2px（v1 算例 172/176
  为 4px 同族问题）——生成不排除，由分配规则 §3.3（<8 阻塞）消解：先占
  174 则 176 阻塞、反之亦然，二者取一后每隙仍 ≈7 道可用。
- **⑤ 上外区与帧顶带**：上外区（内容全域顶=首年份头上方）车道

- **⑥ 末下外区带算例**（v3 审查 M1 补）：设末卡底 global y=508、
  contentH=560 → 车道 y=518,526,534,542,550（≤contentH−10=550，闭区间）

## 3. 分配算法

### 3.1 输入与边序

输入=边列表（序=DB `ORDER BY created_at,rowid` 沿承）+车道表+载入占用
（§6.3）。按输入序逐边分配：先来者占道，后来者避让，避无可避则段级叠加
（裁决④）。

### 3.2 单边分配=最小拐弯确定性搜索

端点=锚选择（§4）产出两锚；首段方向恒沿源锚外法线、末段恒沿目标锚外
法线（桩三元组形态断言沿承，±2° 口径退役为构造保证）；0 拐直连的首末段
即整条路径（不参与错峰指派，见 §3.3）。

搜索=车道图上 Dijkstra：**状态=(车道交点, 来向车道)**（转弯代价仅在同
状态转移出不同轴时产生）；优先级向量 **(拐点数, 曼哈顿长度, y, x, 方向序)**
字典序；settle-first-wins（先出队者定标签）。并列等价路径按此全序取先
（审查 M2 更正：v1 的 0-1 BFS+表全序未定义可执行确定性；本口径=确定性
红线达成——无随机、同输入恒同输出；契约测试按此序手推）。可行性=逐段
满足：①不入死区（端点豁免按 §2.2）；②与占用不冲突（§3.3）；③首末段
长 ≥10（拥塞时错峰延伸，§3.3）；④拐点落车道交点（构造保证——桩端
10+8k 与走廊首道同格，§2.3）。

六态自然产出：同列直连=0 拐锚道；同排同高直线=0 拐锚道（异高改 2 拐 L
形）；门形/阶梯/外圈/掉头=多拐路径。链序与六态构线器整体退役（§5）。

### 3.3 占用登记与间距规则

段级占用表 occupancy.ts：每车道登记已占区间（边 id+区间+段标记）。

- **同道**：跨距重叠 → 后者阻塞（须让道）；仅溢出态（§3.4）或同锚错峰
  桩区（下条）可共线。
- **异道**：|Δ坐标|<8 且跨距重叠 → 阻塞；≥8 或跨距不重叠 → 可行。
  （横竖两轴同规则；跨相位 4px 候选由此消解，§2.5-④。）
- **同锚错峰**（v3 审查 B4 残留修复：指派域有限化）：同锚点出发的同向边
  按边序指派首段长=该锚该向走廊**存活道序列**第 (i mod K) 道（i=同锚边
  到达序、K=走廊存活道数——行隙 K=7（卡底+10..+58）、左缘带 K=1（仅
  x=2））；**桩长不无限增长**，第 K+1 条起确定性复用（k 折回 0），复用
  共线重叠段登记 overlapSpans（§3.4 语义）——耗尽=叠加，不 blocked
  （裁决④）。第 2 条同 left 锚边（K=1）即复用 x=2；第 8 条同 bottom 锚
  边（K=7）复用卡底+10 道，不出撞下卡死区的 156 端。同锚 0 拐直连
  （整条=首末段）不参与错峰：共线前缀按溢出语义登记冲突段（§3.4），
  语义与现状「12 锚全满共享原锚」一致。
- **AnchorUse 重建**（审查 M6 补）：锚占用与车道占用同表重建——pin 全量
  预注册（输入边序）→ 载入边 anchorMarks 回放 commit → 重排边按序 pick/
  commit。

### 3.4 溢出（容量不足，裁决④）

可行路径不存在（仅因线占用耗尽）：**忽略线占用**（死区恒生效——叠加也
不穿卡）重跑搜索取最优，随后与占用表逐段比对：仅实际冲突区间登记为
`overlapSpans`（「车道:区间」串列表，段级 provenance——审查 M3 更正：
v1 整条布尔豁免退役）；边级 `overlapExempt=true` 保留（观测兼容）。溢出
路径的全部段照常登记占用（后续边正常避让）。⑥c 断言只对 overlapSpans
命中的区间对豁免（§8）。0 拐直连共线前缀同用 overlapSpans 承载（§3.3）。

忽略占用仍无路径 → 回退 blocked 空 d（INV-79 合同沿承：提示一次、数据
保留、净空恢复自动重试）。blocked 保留面（v3 审查 B6 更正：v2「零 blocked」
过强，与现状锁定合约冲突）分两类：
- **端点封死族**（合法数据态，非缺陷）：钉定锚外法线终桩 10px 全程落入
  第三方障碍死区（月标压顶等）——终段方向被锚构造锁定，车道无法消解。
  现状锁定例沿承（lineage-finalize-gate 月标压 top/1 锚 blocked 态——
  行为等价迁移）。
- **布局性不可达**（预期零触发，触发即缺陷立案）：每隙 ≥7 道供给+边侧道
  +外区带三路冗余下中段无路。

## 4. 端点接驳（12 锚体系保留）

  散开（同侧→邻边→对边、12 满共享原锚）、钉定 pin 预注册+直取禁动、

- 桩语义：桩=首/末段本身（锚道上的段，长 ≥10，拥塞错峰 10+8k——现行
  s0=10+i·9 的 9 改 8 对齐步长）；「桩区禁 Z-jog」由「首末段=外法线桩+
  拐点落车道交点」构造承载（zapply/间隙位移族退役）。

## 6. 更新计算集（裁决⑥承载）

### 6.1 快照与帧身份（审查 M4 补）

LayoutSnapshot 扩展：`contentH`、每帧 `frameKey`（采 DOM data-frame-key）
、卡→frameKey 映射（采 DOM closest('.month-frame')）。B2 契约变更，
INV-SLOTGRID-02 同步。

### 6.2 障碍变（卡增删/拖拽 settle/月分组变）——框内全重排+牵出集

**月域语义（2026-11-19 呈裁澄清定案）**：某月改动只重算该月内部+该月与
其他月的连线；其他月份内部的线（含用户手动调整）完全不动——手动 via
的清除域**仅限端点卡落在变化帧的边**（月内边+直连边）；穿框而过的手动
边保留 via，若路径因改动碰障=blocked 承接（INV-79 合同：数据保留、净空
恢复自动重试）。

计算集 = 端点卡落在任一**变化帧**（新旧 frameRect 并集判定）的边 ∪ 现路
径**任一段与变化帧新旧 rect 并集真实相交**的边（bbox 仅粗筛；穿框边不
重算则改月卡片可压上其陈旧路径——正确性必需的牵出面）∪ **引用消失车道
的边**（审查 M7 补：旧路径用了新车道表没有的坐标 → 自动边入集重排保坐
标封闭；手动边保留 via 走 blocked 承接）。所有变化帧并集后**单次**按
全局边序分配（避免跨月边先后次序依赖）。集内 manual 边：端点在变化帧
者 via 清除重排（§6.4），其余不动（§6.3）。uiScale 档变/W 变/空图复位=
全局布局变化 →计算集=全图。

### 6.3 载入占用（carried）

集外边现有路径段+anchorMarks 预登记（只读固定，§3.3 重建规程）。routeAll
签名=`routeAll(edges, snap, onWarn?, carried?)`（审查 m1：onWarn 位置
沿承，carried 第四参——纯函数契约不破：给定输入含 carried 恒同输出）。
**固定边占用优先=呈裁点 §11-3**：集外较晚边先占 vs 全局边序纯度不可兼得，
本设计取「集外不动」（裁决⑥字面），会话内边序对纯序有局部反转（早到
重排边避让晚到固定边）；重载无 carried=全图干净分配，占用链差异可致框
外个别线跳变（预期罕见）——呈裁点 §11-3 合并。

### 6.4 手动线与 via 数据

- 障碍变重排集内 manual 边（**仅端点卡在变化帧者**——2026-11-19 呈裁
  澄清）：via 置空重排。落库经写队列 NULL；**并入引发它的同一撤销单元**
  （审查 M8 更正：v1「快照含 edges 即覆盖」不成立——setEdgeVia 自起
  单元）。机制=复合 store 动作 `applyObstacleReroute`（单 beginUnit 内：
  卡片落位+via 批清除+路径更新一次入栈）；拖拽 reorder 既有 beginUnit
  并入本动作。**undo/redo=历史恢复，不触发 via 清除**（恢复的前布局即
  via 有效布局，终门复检通过）；只用户障碍突变（拖放/增删/导入）触发
  清除。状态迁移（障碍变→清 via→undo→redo→再 undo）入 B3 契约测试。
- via 手动调整（四提交口）：不触发全局重算——**触发分类按 edgeId+几何
  字段 diff**（审查 M5 更正：v1「inputs 引用变+布局未变」过宽）：via-only
  （恰一条边 via 变、端点/钉锚/边集不变）→单边重投影（manual 态不参与
  分配；是否占车道随 §11-1 分支——甲=登记占用供后续避让、乙=不登记，
  终门沿承）；视觉字段-only（线名/颜色/虚线）→零重算；新增/删除/换端走
  §6.4 下条。每类触发各一契约例+其余边逐字节不变断言。消失车道牵出扫描
  （§6.2）消费域=自动边 laneMarks（甲分支含 manual 边 pts 比对；乙分支
  manual 自由坐标不触发牵出——审查 M11 闭合）。
- 画线/删线/换端：新边按 carried 单独分配；换端=清 via 重排该边（沿承）
  ；删线释放占用（下次触发回收，无即时重排——沿承）。
