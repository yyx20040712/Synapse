## §1 应用壳

- **顶栏 38px**：最左 **Synapse 艺术字签名**（Georgia 斜体，「a」用 accent 色，垂直居中，A15/D3）；**全局搜索水平居中**（320px，Ctrl K）；右侧 caption 三键（close 悬停红）。无主题钮（A6=设置页）。
- **B站式窄轨侧栏 72px**（自「课题」始，无 logo，A15）：顺序=课题→下载→（留白分隔）→文献库→阅读器→脉络→（贴底）设置。图标上置+10px 标签下置；选中=accent 色软胶囊；hover=--line-soft。
  - **课题**（A10）：点击弹课题选择列表（250px 弹层：色点+全名+篇数）；选中后**侧栏图标色点与标签文字变为课题短名**，状态条课题名联动。课题间数据隔离（ADR-0018 不变）。
  - **下载**（A8）：**文献搜索与下载引擎占位**——规划中未实现；点击 toast 明示；无角标。
- **状态条 26px**（等宽字）：课题名·篇数｜脉络 N 节点/M 连线｜已选｜…｜自动保存·时间｜主题名｜待办提示。仪表透明度三主题不变。

## §2 三视图规格

**文献库**：筛选行（FTS 搜索+标签胶囊计数+排序）→ 密度列表（编号/题名·期刊/年月/引用/档次/标签 六路信息列，tabular-nums，hover=信号橙游标线，选中=靛蓝左缘条+描边）→ 右侧 316px **规格表抽屉**（等宽大写键名+右对齐值、四格指标=引用/通读/标注/笔记、跨域关联行=脉络月框+AI 评估（后置章））。

**阅读器**：多 tab + 工具栏（图标化五色标注/选择模式/单双页/页内搜索）+ 左侧三 tab 侧栏（目录/缩略/笔记）+ 纸面页列。**纸面三主题规则**：白天=白纸；**夜间=反色暗纸 #242830/亮字**（A7）；护眼=奶油纸 #f7efdc/褐字。批注弹层/保存态语汇不变（沿用现行强项）。

**脉络（核心重设计）**——纵向「年+月」时间线，**旧→新自上而下**（A1）：

1. **结构**：年份头（23px 衬线年份数字+篇数+细线）→ 月框（`1.6px dashed --month-dash` 圆角 12px，**统一满宽右边缘对齐** D1，框间距纵向 26px/年距 38px A11，右侧留 58px 绕行走廊）；**未定月**=灰实线独立收纳框（同年内末位）。
2. **文献小卡 104×52**（A9）：底色 `--mini-card`（比月框内更深）；三行=题名(9.3px 粗)/核心想法(8.2px 一行截断)/年月+引用(7.5px mono)；徽章=「核」（核心，accent 底）「综述」（虚线框）；骑缝编号 mono。**卡距横纵 20px（2×，D2）**——逻辑线从空地穿行。
3. **砖砌行错位（A2 修正口径）**：月框内卡片换行后，**偶数行整体右移 62px**（半卡 52+半隙 10），父子连线从行间空隙穿过互不遮挡；JS 按实际 offsetTop 分行计算，重排/改月后重算（0.25s 过渡）。
4. **连线系统**：四基础型=继承（实线）/推断（虚线）/综述关联（点线）/人工补线（橙虚线）；**每型下可建子线型**（B2/A14，CAD 式：子型=颜色×线纹组合，初始含 继承·数据驱动 accent / 继承·物理机理 --sub2，新建自动轮转调色板）。**路由三式+避让四检（A13/B3）**：
   - 垂直式（父子）：源卡底→目标卡顶贝塞尔，走框间空隙；
   - 平级弧（综述/人工）：源右缘→右走廊→目标右缘水平弧；
   - 绕行折线：跨年被挡线走右侧走廊（侧出口被同行右邻挡→**改由源卡底部经框间空隙出**）；
   - **避让四检**：垂直带检测／弧入口横道／弧回程扫掠带／目标月标注压口右移（入口 x 移至标注右侧）。任何一检被挡即降级换路由——**连线永不穿过文献卡与月份标注**。
5. **交互**：
   - **拖拽=月内槽位重排**（A12/B1）：拖动时虚线「置入」槽实时标出候选文献位（随指针在两行交错位间移动，框外槽淡化），松手飞入槽位；**跨月拒绝**（飞回+提示）；
   - **编辑模式**（A3）：工具条「编辑脉络」→ 卡片亮**月标**（点击弹月份列表，选后卡片**飞行动画**移框+框高动画）；**点连线弹展开式线型选择器**（基础型分组▸子线型▸组内「＋新建线型」，单开手风琴）；「新建连线」=点源卡→点目标卡→选线型；
   - 检查面板（右侧 288px）：题名/徽章/核心想法/标签/人工笔记/**AI 评估笔记（后置章）**；单击卡选中。
   - 空月框保留（A4）+「拖入提示」；计数（月标签/年篇数）实时。

## §3 结构化数据规格（B4 核心——AI 易读）

**lineage v2 模型增量**（`src/shared/models/lineage.ts`，zod 单源，[locked-change]）：

```ts
LineageNode += { month: number | null }        // 1..12；null=未定月框（year 已有）
LineageEdge += { sub: string | null }          // 子线型 id，null=基础型默认样式
LineageGraph += { lineTypes: LineTypeGroup[] } // 图级线型定义（随图持久化）
LineTypeGroup = { base: 'tree'|'inferred'|'ref'|'manual', subs: { id, name, color, dash, w }[] }
月内序 = 数组序（无显式字段，graph.nodes 按年月分组后组内序即槽位序）
```

- **迁移 011**：`lineage_nodes` +`month INTEGER NULL`；`lineage_edges` +`sub TEXT NULL`；`lineage_graph_meta` 新表（或 KV）存 `lineTypes` JSON。草案，实施票定稿。
- **AI 可读导出**：corpus 导出五件套扩展 `lineage.json`——确定性键序、snake_case、语义字段（`month`/`line_type.base`/`line_type.sub`/`core_idea`/`catalog_no`），并附 schema 版本号；导出即本档 §2 脉络全量（不含 UI 态）。
- 基础型语义不变（tree 单父/拒环、ref 综述限定、manual 豁免单父——INV-27 扩枚举不改守卫逻辑）；**不触发 ADR-0014 v2 DAG**（仍是树+旁挂边，时间线只是布局媒介）。
