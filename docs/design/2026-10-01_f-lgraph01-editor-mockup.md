## §2 状态机前置（宪法：store+异步+用户输入工单强制）

### 2.1 模式态（互斥单选，页面级）

| mode | 画布交互 | 工具组 | 导航窗格 | 点卡联动 |
|---|---|---|---|---|
| `edit` | 卡拖拽/线编辑/画线 | 可用（§3.3） | 可用 | 选中卡+详情面板 |
| `browse` | 拖动平移（小手）+滚轮纵向 | 隐藏（仅模式栏） | 可用 | 详情面板（P-13） |
| `focus` | 单击卡 toggle 聚焦；其余同 browse（平移+滚轮） | 隐藏 | 可用 | toggle+详情面板 |

- **进页缺省=browse**（拟——呈裁点 P-1）。
- 模式切换**不丢编辑会话暂存**（edit→browse→edit 暂存与撤销栈原样；
  呈裁点 P-2）。
- ctrl+滚轮在三模式均生效（缩放不与拖拽冲突——滚轮与 pointer 正交）。

### 2.2 编辑会话态（dirty×保存——v97-3 定案展开）

```
clean ──任一编辑单元──▶ dirty ──点保存──▶ saving ──成功──▶ clean（撤销栈基线重置）
  ▲                      │                   │
  └──undo 回到基线────────┘                   └──失败──▶ dirty（保持可再存+错误行内提示+重试钮）
```

- 编辑单元=单次拖放（卡/顶点/段）/加点/删点/重置走线/端点重连/画线/
  删线/命名提交（含线型行内改名——N-r1-1）/线形变更——与撤销栈
  单元**同构**（一单元=一撤销步）。
- **saving 态**（现行保存 chip「保存中…/失败+重试」语义吸收）：保存
  中=工具组锁定+保存钮 spinner 态；失败=dirty 保持+行内错误+重试
  （不入撤销栈）。
- **dirty 态退出页面/切图=未保存提示，两分支**（B-2 闭合）：
  - 取消=留在当前图/页面，暂存与撤销栈原样保留；
  - 确认=**弃暂存**（不落库）+撤销栈清+切换/退出；再进入=自库态起栈。
- 保存=暂存批量落库（写队列合并 IPC），成功后 clean+栈基线重置+
  保存按钮变暗。

### 2.3 聚焦态（focus 模式内——二轮批复重写）

- `focusSet ⊆ nodes`；单击卡=toggle（加入/移出）；**再点同卡=取消该卡
  聚焦**；**点空白=no-op**（v97-2——不取消聚焦）。
- **聚焦视觉=仅标记被点卡**（accent 边框）——**上下游闭包照亮删除**
  （二轮批复覆盖 v95-3「照亮上下游」子句：多卡各自独立标记时选中
  语义必须可逆清晰，联动照亮与「再点取消」冲突）。
- 其余非聚焦卡+全部线 dim（opacity 0.3，非隐藏——v95-3 dim 面保留）；
  dim 元素 hover 临时回升 0.6 可读探查。
- 退出=点浏览（或编辑）按钮——**单出口**（三轮裁决 2026-10-01：「再点
  聚焦按钮退出」系冗余取消——再点聚焦按钮=**no-op 保持聚焦**；覆盖
  v97-2「或再点一次聚焦按钮」子句。「或编辑」=三模式互斥的自然结果
  [点编辑即离场聚焦]，非新增出口）→focusSet 清空（=呈裁点 P-3 语义
  不变：退出后再进=空集）。
- 切图/切文件夹→focusSet 清空（图域隔离）。
- **呈裁点 P-18**：聚焦 dim 范围=非聚焦卡+全部线（拟推，含聚焦卡
  邻接线）vs 仅非聚焦卡 dim 而线全亮（备选）。

### 2.4 画线子态（edit 模式，tool ∈ {select, draw-solid, draw-dashed}）

```
idle ──点画线工具──▶ armed ──pointerdown 近锚(12/卡±6)──▶ dragging
dragging ──pointerup 落另一卡近锚──▶ 建边（**继承当前线型名**——P-14）──▶ idle(select)
dragging ──pointerup 空白/同卡──▶ 取消 ──▶ idle(armed 保留)
armed ──切 select/切模式──▶ idle（画线中止）
```

### 2.5 手动调线子态（edit 模式——承接 F-LINEAGE-02 design-final §2.3）

```
idle ──单击线──▶ selected（高亮+手柄集：via 方柄+端点圆柄）
selected ──拖顶点/拖段──▶ dragging（联动轴跟随+磁吸±6）──pointerup──▶ selected
selected ──双击段──▶ 加点（共线中点，同 selected）
selected ──右键顶点──▶ 菜单[删点(L 形重连)/…]
selected ──右键线身──▶ 菜单[命名/线形/重置走线/删除]
selected ──拖端点圆柄──▶ reconnect 拖拽（换锚/换卡，via 保留）
selected ──点空白/Esc──▶ idle
自动线（无 via）selected──拖任意段 or 加点──▶ 首个 via 落位=转 manual-override
```

- **术语界定**（W-2 闭合）：「自动线/自动边」=甲链自动路由之边
  （F-LINEAGE-02 域），**与 AI 生成无关**（票面③ AI 不生成线原则
  恒立——全部边皆人工建，仅路由形态分自动/手动 override）。
- **收尾转移**（W-5 闭合）：selected/dragging/reconnect 任一态下
  切模式或切图 → 态清空；dragging 中断（指针移出画布/失焦）=
  pointerup 等价收尾——该拖放单元**不成立**不入撤销栈（via 回拖前
  定态）；reconnect 拖拽中断=端点回原锚。
- 撤销单元粒度=F-LINEAGE-02 design-final §2.3-9（单次 pointerdown→up
  含联动子步与磁吸落点=一单元）。
- 穿卡警示=dragging+selected 态渲染，零持久化（同源 §2.3-8）。

### 2.6 跨格序列拷问面（对抗审重点）

1. edit(dirty)→切 browse→切回 edit：暂存保留、栈不清、保存钮仍亮。
2. edit(dirty)→保存→undo：栈基线已重置→undo 无效（不回到保存前）。
3. focus(集非空)→切 browse→切回 focus：focusSet **清空**（模式级退出
   语义一致——呈裁点 P-3 默认=清空）。
4. draw dragging 中→切模式：画线中止无残留半成品边。
5. 卡删除→边级联删（含 via）；undo→边+via 整体恢复（级联删=一单元）。
   卡删除入口=现行卡菜单域（LineageNodeMenu，非本批重设计面——级联
   语义随实施②批核对，W-4 闭合）。
6. 编辑中双击卡跳阅读器→返回：会话暂存保留（阅读器不触碰脉络暂存）。
