## §2 状态机前置（宪法：store+异步+用户输入工单强制）

### 2.1 模式态（互斥单选，页面级）

| mode | 画布交互 | 工具组 | 导航窗格 |
|---|---|---|---|
| `edit` | 卡拖拽/线编辑/画线 | 可用（§3.3） | 可用 |
| `browse` | 拖动平移（小手）+滚轮纵向 | 隐藏（仅模式栏） | 可用 |
| `focus` | 单击卡 toggle 聚焦；其余同 browse（平移+滚轮） | 隐藏 | 可用 |

- **进页缺省=browse**（拟——呈裁点 P-1）。
- 模式切换**不丢编辑会话暂存**（edit→browse→edit 暂存与撤销栈原样；
  呈裁点 P-2）。
- ctrl+滚轮在三模式均生效（缩放不与拖拽冲突——滚轮与 pointer 正交）。

### 2.2 编辑会话态（dirty×保存——v97-3 定案展开）

```
clean ──任一编辑单元──▶ dirty ──点保存──▶ saving ──成功──▶ clean（撤销栈基线重置）
  ▲                      │                   │
  └──undo 回到基线────────┘                   └──失败──▶ dirty（保持可再存+错误行内提示+重试钮）
```

- 编辑单元=单次拖放（卡/顶点/段）/加点/删点/重置走线/端点重连/画线/
  删线/命名提交/线形变更——与撤销栈单元**同构**（一单元=一撤销步）。
- **saving 态**（现行保存 chip「保存中…/失败+重试」语义吸收）：保存
  中=工具组锁定+保存钮 spinner 态；失败=dirty 保持+行内错误+重试
  （不入撤销栈）。
- **dirty 态退出页面/切图=未保存提示，两分支**（B-2 闭合）：
  - 取消=留在当前图/页面，暂存与撤销栈原样保留；
  - 确认=**弃暂存**（不落库）+撤销栈清+切换/退出；再进入=自库态起栈。
- 保存=暂存批量落库（写队列合并 IPC），成功后 clean+栈基线重置+
  保存按钮变暗。

### 2.3 聚焦态（focus 模式内）

- `focusSet ⊆ nodes`；单击卡=toggle（加入/移出）；**点空白=no-op**
  （v97-2 定案——不取消聚焦）。
- 照亮集=`focusSet ∪ 上游闭包 ∪ 下游闭包`（引用方向沿边传播）；
  其余卡+线 dim（opacity 0.3，非隐藏——v95-3，一轮视觉审自 0.25
  上调可读下限，口径 P-12 呈裁）。
- 退出=点浏览按钮或再点聚焦按钮（模式级）→focusSet 清空（=呈裁点
  P-3 默认，非独立定案）。
- 切图/切文件夹→focusSet 清空（图域隔离）。

### 2.4 画线子态（edit 模式，tool ∈ {select, draw-solid, draw-dashed}）

```
idle ──点画线工具──▶ armed ──pointerdown 近锚(12/卡±6)──▶ dragging
dragging ──pointerup 落另一卡近锚──▶ 建边（命名「待命名」）──▶ idle(select)
dragging ──pointerup 空白/同卡──▶ 取消 ──▶ idle(armed 保留)
armed ──切 select/切模式──▶ idle（画线中止）
```

### 2.5 手动调线子态（edit 模式——承接 F-LINEAGE-02 design-final §2.3）

```
idle ──单击线──▶ selected（高亮+手柄集：via 方柄+端点圆柄）
selected ──拖顶点/拖段──▶ dragging（联动轴跟随+磁吸±6）──pointerup──▶ selected
selected ──双击段──▶ 加点（共线中点，同 selected）
selected ──右键顶点──▶ 菜单[删点(L 形重连)/…]
selected ──右键线身──▶ 菜单[命名/线形/重置走线/删除]
selected ──拖端点圆柄──▶ reconnect 拖拽（换锚/换卡，via 保留）
selected ──点空白/Esc──▶ idle
自动线（无 via）selected──拖任意段 or 加点──▶ 首个 via 落位=转 manual-override
```

- **术语界定**（W-2 闭合）：「自动线/自动边」=甲链自动路由之边
  （F-LINEAGE-02 域），**与 AI 生成无关**（票面③ AI 不生成线原则
  恒立——全部边皆人工建，仅路由形态分自动/手动 override）。
- **收尾转移**（W-5 闭合）：selected/dragging/reconnect 任一态下
  切模式或切图 → 态清空；dragging 中断（指针移出画布/失焦）=
  pointerup 等价收尾——该拖放单元**不成立**不入撤销栈（via 回拖前
  定态）；reconnect 拖拽中断=端点回原锚。
- 撤销单元粒度=F-LINEAGE-02 design-final §2.3-9（单次 pointerdown→up
  含联动子步与磁吸落点=一单元）。
- 穿卡警示=dragging+selected 态渲染，零持久化（同源 §2.3-8）。

### 2.6 跨格序列拷问面（对抗审重点）

1. edit(dirty)→切 browse→切回 edit：暂存保留、栈不清、保存钮仍亮。
2. edit(dirty)→保存→undo：栈基线已重置→undo 无效（不回到保存前）。
3. focus(集非空)→切 browse→切回 focus：focusSet **清空**（模式级退出
   语义一致——呈裁点 P-3 默认=清空）。
4. draw dragging 中→切模式：画线中止无残留半成品边。
5. 卡删除→边级联删（含 via）；undo→边+via 整体恢复（级联删=一单元）。
   卡删除入口=现行卡菜单域（LineageNodeMenu，非本批重设计面——级联
   语义随实施②批核对，W-4 闭合）。
6. 编辑中双击卡跳阅读器→返回：会话暂存保留（阅读器不触碰脉络暂存）。

## §3 交互域规格（幕次呈样）

### 3.1 顶部模式栏（S1/S2）

- 位置=脉络页顶栏居左分段控件（segmented）：`[编辑] [浏览] [聚焦]`，
  图标+文字（笔/手掌/焦点框），当前态 accent 底白字。
- 右侧=当前图名（mono 小字）——替代退役的并集切换器（图切换入导航
  窗格 §3.2）。
- 缩放指示角标（右下）：`100% ▾`+复位项（ctrl+滚轮联动，范围 50%–200%
  拟——呈裁点 P-4）。**坐标域口径**（W-3 闭合）：缩放=CSS transform
  scale 作用于画布内容层，**内容坐标不变**——候选槽/锚点吸附/磁吸/
  穿卡检测均在内容坐标域判定（指针命中经逆变换换算，与缩放正交）。

### 3.2 左侧导航窗格（S3）

- 形态=Word 导航窗格：固定宽 208px，可收起（收起钮在窗格头）；
  收起态=40px 窄条（仅展开图标）。
- 内容自上而下：
  1. **图/文件夹下拉**（窗格顶）：当前图名+▾；点开=库页文件夹树平铺
     列表（每文件夹一行=其图；主图恒在列）——**每图只显示自身**
     （并集首项退役）。
  2. **时间线索引**：年（衬线数字）>月（两位数）两级，点击=画布滚动
     定位到对应月框；当前视口所在月=accent 指示条。
- 缺省图=库页文件夹上下文同步（进哪个文件夹开哪张图；未选=主图）。

### 3.3 编辑工具组（S5）

顶栏模式栏右侧、仅 edit 模式可见，排布：

```
[保存●] │ [小手选择] [— 实线] [╌ 虚线] │ [颜色下拉■] │ [命名输入框] │ [↶] [↷]
```

- **保存**=软盘图标：dirty=亮+可点+角点标记；clean=灰暗禁用。点击=
  批量落库（§2.2）。
- **小手选择**=默认工具（点选卡/线/框；拖框选=后置增强位，本批不呈）。
- **实线/虚线**=画线工具（互斥单选，armed 态图标 accent 高亮）；线型
  语义=纯视觉（基型收敛=manual 单基型——票面③）。**取舍注记**（W-1）：
  票面原文「线形下拉（该线形下颜色）」——线形仅两值做图标互斥工具、
  下拉承载 6 色，功能等价（线形选择+该线形下选色）而入口更直接。
- **颜色下拉**=当前画线工具色（色板 6 色拟：蓝/橙/绿/紫/灰/洋红——
  呈裁点 P-5）；选中已有线时=该线色（改色即编辑单元）。
- **命名输入框**=选中线时显示该线名（初始「待命名」），回车/失焦提交；
  未选线=占位灰字「选择线条命名」。
- **撤销/重做**=会话栈（Ctrl+Z/Ctrl+Y）；栈空=灰暗。
- **悬停高亮**（v95-6B 认可）：hover 线=同色淡化放大（线宽 1.6→2.6+
  opacity 0.55）——多线交叉视觉聚焦。

### 3.4 卡片四层（S7）

- 竖向 3:4：**104×138**（宽不变=月框内每行容纳数与瀑布错位零影响——

- 四层自上而下：
  1. **标记区**（高 20）：星标（未标记=书页图标线框/已标记=accent 实心

  2. **标签行**（高 16）：域化标签色点+名（与文献库对齐——F-TAGS-02
     联动；最多 2 个+溢出 `+N`）。
  3. **文献名**（弹性区，2-3 行 9.3px 截断）。
  4. **期刊+IF 行**（高 14）：期刊缩写（faint 8.5px）+IF 值（mono

- **星标交互域**（呈裁点 P-6，拟）：browse/focus 模式点星标=toggle；

### 3.5 拖拽分屏体验（S6）

- 拖起态=现行 `.tl-card.dragging` 保留（fixed 离流+微倾 2°+放大 1.05）。
