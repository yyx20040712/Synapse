# 车道网格统一分配——设计需求与用户裁决记录（F-LANEGRID-01）

> 状态：设计票 open（需求已裁决，方案待设计稿）。本文档承载需求与裁决，
> 不承载实现方案——方案由设计岗出稿呈用户审后定。
> 来源会话：runId=20261119-r2c5（R2-C5 压力 e2e 批，2026-11-19）。

## 1. 目标

走线分配模型从现行「六态链分层试探（direct→h-slip→detour→band→
outer-ring→overlap）+域内分离」演进为「全局车道网格统一分配」：间距由
网格步长结构性保证，取代事后分离与跨机制不协调。

## 2. 用户裁决（2026-11-19，逐项）

1. **全网格化**：所有线横平竖直走网格，管道线观感统一——direct 斜连/
   斜切形态废除，间距全域由网格保证。
2. **统一生成网格**：全图一张网格（跨月框/跨年不隔断）；网格更新只受
   起止点（边端点）变动影响之外的布局变化驱动（网格随布局派生）。
3. **卡片即障碍**：卡片填入覆盖的网格段失效；网格不超出月份框左右边界。
4. **溢出=重叠**：网格耗尽时新线直接叠加已有线（按边序后来者叠先来者），
   不从框外/右侧绕行逃逸。
5. **少拐优先**：拐弯规则沿用现行 tie-break 精神（每线拐点尽量少）。
6. **两类更新触发**：
   - 障碍物改变（卡片增删/移动）→该月框内**全部**线条重新分配，
     **含用户手动调整过的线**（手动覆盖不跨障碍变化存活）；
   - 用户对线条本身的改动（via 手动调整）→不触发全局重算，其余线不动。
7. **拐弯圆角**：沿用现行骨架折线 + buildRoundedPath 曲化（r=6→3→0），
   非新增工作。

## 3. 现状将由本设计消解的形态（升硬断言清单）

1. band 跨单元同带共线重合 + outer-ring 车道共享——route-stress-assert
   ⑥c `SHARED_LEVEL_ROUTES` 豁免面：网格统一分配落地后**删除豁免升硬
   断言**。
2. 跨机制近距（残余电平 vs 落位槽/桩/jog 实测可 Δ=1px<s）——INV-115
   负面承诺域随之退役。
3. 外圈候选面枚举类缺陷（R2-C5 缺陷 1 族）结构性消失——分配器无候选
   枚举面。

## 4. 影响面（设计稿须覆盖）

- routing/ 六态构线器（direct/h-slip/detour/band/outer-ring）与占用
  注册表（AnchorUse/SlotUse/ChannelUse/残余分离）的替代或收编方式；
- INV-SLOTGRID-02（坐标集封闭——网格电平集成为唯一坐标源）、INV-112/
  115（槽位/残余域语义并入）、INV-79（blocked 语义——溢出叠加态承接）、
  INV-119③（锚与网格的接驳）；
- 全量契约测试与 e2e 几何断言重基线（量级 ≥ PAD 4→6 场）；
- 手动 via 语义（R2-C3 提交门与「障碍变重排含手动线」的交互）；
- 跨月/跨年边、年份头障碍、空卡位穿越（用户裁决「空卡片可随意穿」随
  网格模型重表达）；
- 更新计算集（月框内全重排的边界：跨月边牵出集、zoom/uiScale 档变、
  layoutKey 接驳）。

## 6. 补充裁决（2026-11-19 设计稿呈裁，runId=20261119-r2c5 续场）

1. **manual 线入网格**（裁决①「所有线」字面确认）：人工调整必须受网格
   约束——via 点吸附车道交点+提交门正交校验+manual 段登记车道占用。
2. **步长=8px**（呈裁点 2 按推荐）：s=6/9 双值统一为 8，首道离卡 10px
   沿承。
3. **更新计算集月域语义**（呈裁点 3 用户澄清）：每个月份的改动只算该月
   内部+该月与其他月份直接连接的线条；其他月份内部（含用户手动调整）
   完全不动——手动 via 清除域仅端点卡在变化帧的边，穿框手动边保留 via
   碰障 blocked 承接。
4. **溢出粒度=段级叠加**（呈裁点 4 按推荐）：仅冲突段叠加+overlapSpans
   段级登记。
5. **异高横连 L 形**（呈裁点 5 解释后待确认）与 **RouteTag 单态化**
   （默认过）见设计稿 §11。
