Synapse 前端视觉方向 · 四稿

2026-09-26 · docs/design/mockups/

本批四稿回答「商用级优秀前端应该长什么样」：第一眼可扫读的层级、状态永远可见、键盘可达、克制的个性、性能上的即时感——这些是地基，任何视觉方向都必须建在上面； 地基之上，一个产品只应该有一个记得住的签名。四个方向各押一个论点、共用同一批智慧水务真实内容，供挑选或组合（例如 C 的文献库密度 + B 的夜面脉络）。 每稿均为离线自包含 HTML，直接双击打开即可。

Ⅰ
内容是主角
壳层（栏/钮/框）退后，纸面、题名、数据站前排；首屏即工作现场。
Ⅱ
层级靠排版
字体三轨制（衬线×黑体×等宽）+灰阶分层，而非到处加框加色块。
Ⅲ
状态永远可见
保存中/已保存/加载中/失败——用户任何时刻知道系统在干什么（本仓强项，保留强化）。
Ⅳ
键盘与焦点
列表/标签页/画布全键盘可达，焦点可见——单人重度工具的效率底线。
Ⅴ
一个签名
全应用只留一处记忆点（菱形/星等/刻度/骑缝章），其余保持安静。
A · 宣纸书房阅读器
现有「暖纸白·墨青·金铜」推熟为中文文献版式：装帧金线、宋体题字、纸面页列。品牌连续性最强。
改造成本 低 · token 全沿用

B · 观测台脉络图 · 夜面
激活仓内已定义未消费的「脉络星象板」夜面 token：核心文献=一等星，年份=黄道坐标带，选中星连线点亮金流。
改造成本 中 · 存量 token 激活

C · 精密仪表文献库
文献库=测量数据集：刻度尺、等宽读数、游标线、规格表抽屉——高密度高效率的仪器面板语汇。

使用说明　① 四稿可单选、也可组合（A 壳层 + C 文献库 + B 夜面脉络 = 「品牌壳·仪表库·星图脉络」三段式）。 ② 每稿文件内附设计注记（token/字体/签名/可迁移优先级），选定后按现行流程进入设计链与立票，token 终值仍走 mockup 单源惯例（theme.css 头注在案）。 ③ 脉络两稿（B/D）保留现行全部语义约束（tree/ref/manual 三边、核心出度≥2、综述启发、单父拒环 INV-27），仅换视觉媒介——大改语义请另行裁决（ADR-0014 v2 DAG 升版条件）。
