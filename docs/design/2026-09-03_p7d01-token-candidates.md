## §3 候选方向（并列呈报，非推荐）

**方向甲「最小增量·零视觉差」**：theme.css 增补 token 直接映射 §2 收敛值（`--fs-13: 13px` 类命名待定+`--dur-fast: 0.14s`/`--dur-instant: 0.08s` 等），29+32 处逐值替换——**像素级零视觉差由无头截图 diff 验收**（真机复评不回退条款的最强满足形态）。B/C 消费基座（材质变量）留玻璃质感票再铺。
- 代价：token 名与刻度语义弱（值即名）；后续若做语义刻度需二次改名。
- 收益：纯机械迁移，闲时全可动，零用户决策（除命名口味）。

**方向乙「语义刻度重构」**：设计语义档位（如字号 5~6 档 `--fs-caption/--fs-body/--fs-title/...`），12 个现值归并入档——**半值系归并必然产生 0.5px 级视觉变化**（9.5→10 等），属方向级视觉决策，须 mockup+用户逐档裁决后实施。
- 代价：用户在场轮依赖+归并裁决 12 值×视觉复评。
- 收益：终态刻度干净，玻璃 UX 战役的字体系统一步到位。

**方向丙「tailwind 对齐」**：主体已 84%/97% 说 tailwind 语言——硬编码面尽量迁 tailwind class（text-[9.5px] arbitrary 形态），CSS 变量只承载 tailwind 表达不了的面（主题联动/材质）。
- 代价：arbitrary class 散布=另一形态的硬编码（INV-11 同型债换皮）；与「变量单源+lint 轨道」红线方向相反。
- 收益：迁移面最小、与既有代码风格一致性最高。

**B5 缩放复核注记**（用户已裁决认可）：切换器面板 125% 档恒定字号反差 ×1.248=可接受设计；token 铺设时以统一缩放体系复核=**产出核查结论供档，如统一体系会改变面板现状则另行报裁**（本案册不预改）。
