## 规则区

- **增量登记义务**：新增治理面（机检脚本/CI 关卡/强制文档字段·机制）立案时
  必须附**退出条件与评审触发器**并登记本册——无退出条件者不予立票（AGENTS.md
  「治理面生命周期」条款）；F-GOV-01 自身三处治理面变更（本册/宪法条款/日落
  规则）即按此登记（其退役触发器=下方元机制条，非表行形态）。
- **默认评审周期**=随批顺带（收口轮翻台账注记）+季度全表核；表内「默认」
  即指此，个别差异见表内注记。
- **拦截实绩书写口径**：只填有档可查的真实拦截（出处=提交号/交接书 vN/
  教训档 §N/票面）；查不到填「无在档记录」，禁虚构；防线未触发如实记录
  （护栏见说明头 D-GOV-16）。
- done 票 summary 日落（增量规则）：某票收口翻票后，历经 3 次交接书批次滚动
  （「批次」=新 vN 交接书 §2 全项标毕的收口档）仍未再触及的，由当值收口主控
  在其收口轮顺带瘦身为「结论句+（全案=tickets/archive/<票号>.md）」——人工判据
  （registry 无日期字段，批次数以交接书 vN 序为轴），不作机检。
  起算点=该票收口翻票所在批次**之后**的首个新 vN 收口档为第 1 批（中途收口
  当批不计；收口当批内的触及同样不计入「再触及」）；「再触及」=该票 file 面
  被任何后续提交改动、或其 registry 行/archive 件被修订（门审提及、他票
  纯引用不算触及）。
- 已瘦身票再触及（勘正/回写类）：改对应 archive 件，registry 行结论句仅在结论
  变化时改写；README 索引行同步。
- **退役触发器书写判据**：新登记行禁填「无」——恒设面须注主控裁决指针；存量
  「无」行实测集=③④⑤⑦⑬⑰⑱与①基础段（①为混合式：基础段无退役面+扩段有
  触发器），补注时点=该行被触及**或季度全表核**（先到者，防长期不触及的
  无限期滞留）。有机拦截与变异红证/TDD 红证在实绩栏须分开标注（变异红证=
  防线载荷自证非有机拦截；存量行红证标注随触及统一）。
- **元机制退役触发器**：本登记册、AGENTS「治理面生命周期」条款与日落规则三者
  作为元机制的退役=治理减容机制经季度评审被用户裁决废除/重构——与表行同规
  （撤/并须主控裁决+宪法修订流程）；元机制不享「无退出条件者不予立票」豁免，
  其存续即持有本条退出条件。
- 沿革注记（F-GOV-01 两单元实录）：**单元一存量消化实录（2026-09-28）**=
  registry done 票 summary 229/229 瘦身+归档、INV 主表 82→76 行（提交
  68a7a0ba866——主控独立口径全量复算逐字节等价，数字链与 KB 对照=仓外
  scripts-audits/F-GOV-01/30-closure-nums.md）；A1 反引号模板串多行=已知逃逸边界（probe
  实证仓外 F-GOV-01/raw03；单引号换行由 tsc 拦）。
- A2 check-tickets fieldOf 名锚定=「字段序不变」实际必需面仅 (id,file) 前两位。
- A3 INV 瘦身短语级重组口径=数字/专名全溯源、连写为压缩重组（复算基准=
