# 外壳级不变量登记册（跨模块行为的单一真相源）

> **为什么存在**：骨架与工单治理静态结构（代码放在哪、谁依赖谁），而状态时序、
> 模块接缝、未声明的默认假设长在骨架管不到的地方。本册登记这些
> **没有天然归属文件的行为不变量**，每条注明强制方式与锚定状态。

### 术语说明

- **隔离一审**（历史称门一）：实现完成后由独立子代理只凭完整 diff 做对抗式审查。
- **终审**（历史称门二）：另一独立子代理复核隔离一审结论并做实证验证。
- **红证**：先证明测试会失败的证据（先让测试红一次再还原）。
- **锚定**：有机器防线持续验证；**已锚定**=防线在场；**负锚**=禁词清单 grep
  反向锁定（命中即红）。
- **欠账**：声明了但当前环境做不到、已登记待补的缺口。

> **规则**（对应 AGENTS.md「设计先行」）：
> 1. 新增/修改跨模块行为时必须同步本册——未登记 = 未定义行为。
> 2. 每条不变量必须给出强制方式（单测 / lint / e2e / CI / 架构评审）。
> 3. 「未锚定」= 欠账：只靠人审或纯声明，无机器防线。接手任务优先补锚。

## 维护规则

- 状态列三档：**已锚定**（有机器防线）/ **部分**（防线有洞）/ **未锚定**（纯声明或人审）。
- 锚定方式优先级：lint/CI > 单测 > e2e > 架构评审（越靠左越不可绕过）。
- 本册与 ADR 的分工：ADR 记「为什么这样设计」（决策+取舍），本册记「什么必须永远成立」
  （不变量+防线）。小而致命的声明（如 INV-01）配得上登记，不必等到"配得上 ADR"。
