### 2.2 步骤机（终态）

- ⓪ 定位安装包：`--installer` 显式指定，否则取 dist 内最新 `*-setup.exe`
- ① 静默安装：mkdtemp 双临时目录（路径无空格防御）；`/S` 与 `/D=` 单 argv、
  无引号；timeout 120s + SIGTERM 前置检查
- ② 沙箱启动：SYNAPSE_USER_DATA 指向临时目录，隔离真实用户数据
- ③ 存活采样：8s 窗口每 2s 采样一次进程存活；EPERM 视为存活
- ④ 清理与卸载：taskkill /T /F（timeout 30s）→ 卸载器 /S（timeout 30s；
  error/status 即时报，卸载成效以完整性断言为准）
- ⑤ assertUninstalled（≤30s 轮询）三分：
  - 安装目录消失 = 最干净，PASS
  - 空壳目录 = rmdirSync 代清理，TOCTOU 三分：ENOENT = 外部已清理；
    瞬时占用 = deadline 内重试；超时 = FAIL
  - 非空且超时 = FAIL
- ⑥ assertRegistryClean：HKCU / HKLM 两棵 Uninstall 树 `reg query /s /f`
  搜 appId `io.github.yyx20040712.synapse` 与显示名 `Synapse Remake`
  两关键字；退出码三分：0 = 命中残留 FAIL / 1 = 干净 PASS / ≥2 或 error
  或超时 15s = 查询失败 FAIL；stdio pipe 附 stderr 便于定位
- ⑦ 现场处置：`--keep` 保留现场，否则删临时目录
- 失败路径：打印失败步骤名 + 现场路径，exit 1

超时常量四件套：安装 120s / taskkill 30s / 卸载 30s / reg 查询 15s。

## 3. 修复循环全记录（规约修订 + 四轮回炉，审计深度核心）

### 3.1 第 0 轮：规约修订（上游缺陷裁决）

- 现象：初版真跑两轮 FAIL，同一根因——上游 electron-builder#1298：NSIS
  静默卸载末尾 RMDir $INSTDIR 时序性失败，留空目录壳；文件清零、
  注册表清空、卸载器自删均正常完成
- 处置：实现方停手报告二选一，主控裁决方案 a——规约④对齐行业卸载语义
  （空壳属已知无害残留，由脚本代清理），同时加严（HKCU/HKLM 注册表强断言）
- 方案 b（customUnInstall 钩子）存档不做：改写卸载流程的风险大于
  空壳 cosmetics 的收益

### 3.2 第 1 轮

- NIT 裁决：NIT-2 恒真冗余确认，顺手修；NIT-1 驳回——190 行系授权
