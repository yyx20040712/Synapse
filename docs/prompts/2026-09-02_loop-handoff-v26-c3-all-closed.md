- **「票面字面形态被锁定用例击红」的自裁范式**:实现者发现票面建议形态
  (初始 resolved 链)破坏既有锁定用例的时序形状(save() 后同步 resolve 桩
  依赖 invoke 即发)→自裁改 null 哨兵+保验收线(行为零变)——**票面形态
  建议让位于锁定用例语义**,自裁申报后门一/门双复核。写票面时实现形态
  标「建议」而非「必须」的又一依据。
- **RED 伴生信号的对账义务**(W1 教训,接 F-D4 EBUSY 同族):RED raw 里
  failed 断言之外的任何信号(Errors/unhandled/文件级条目)都必须申报并
  定性——「红由断言产生,伴生信号与红无因果」要给源码级解释,不默认无害。
- **门二 e2e 免跑的论证形态**:e2e 面判断要给「哪条 e2e 用例覆盖该路径+
  新代码在该路径上与旧行为逐 tick 等价」的具体论证(在场用例+等价推演),
  不是「没改 e2e 所以不跑」。
