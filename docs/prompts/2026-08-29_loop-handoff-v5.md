## 4. U2' 脉络自动化案册（方向级——须用户先选，L6 ⑤c）

背景：ADR-0014 原裁决=梳理智能体产物经文件协议导入（现状）。用户新方向
=AI 读文献**自动**生成与更新脉络。三候选：

- **案 A 全自动**：AI 笔记导入完成时自动 upsert 脉络节点（paperId 绑定）
  +按笔记内容自动建边（综述识别→ref 参考边）。零手工；风险=误边/噪声
  入图（需撤销面）。
- **案 B 半自动（推荐起点）**：AI 导入完成弹「检测到可入图文献——建议
  N 节点 M 边」确认条（一键应用/忽略明细）；应用走既有 upsert 增量链
  （零清空）。
- **案 C 导入安全感**：保持导入制但①入口内置（应用内文件选择/ai-sensor
  目录监控）②导入前确认弹窗「将替换现有 N 节点——继续/改增量合并」。
- 附加子项（各案可叠加）：**让位布局**=卡片重叠自动错开（v1 手工覆盖
  已有；自动避让=布局增强票）；「流程图美观」=可再出 mockup 候选。
