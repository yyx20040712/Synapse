## 3. 本场方法论资产

- **「预裁被推翻」的档案形态**:票面 §1 主控排除项(平移不变性论证)
  被注入实验一跑推翻——**排除项的论证范围(单帧内成立)被错误推广
  (跨帧两次测量)**;排查票预裁要写论证的适用边界,不只写结论。
  好在票面同时要求注入实验(机制直接证明)——预裁与实验并存时实验
  裁决预裁,这是票面结构的胜利不是预裁的胜利。
- **双记录器形态(事件驱动>轮询)**:rAF 采样在 Electron 失焦窗
  **零执行**(backgroundThrottling)——事件驱动(scroll 捕获监听+
  MutationObserver style filter)零轮询零遗漏且不受可见性节流;
  探针仪表选型先问「目标事件是什么」再选记录机制。
- **位形等价性是探针有效性前提**:原路径测量**先行**(一切仪表殿后)
  =与原用例 t0 位形等价;仪表先行会给 resolve 留 settle 时间而掩盖红
  (门一 W-5 进一步限定:样式断言链删减使失效窗口暴露条件不等价——
  位形等价声明要写清等价在哪一段)。
- **稳定门的「一致≠结束」盲区(门二 W-A)**:双采样一致不能区分
  「跳变已结束」与「未开始」——稳定门类修法要加前置观察窗+连续多
  点;显式终态标志不可得时,概率加固+限定表述如实入档(不称通杀)。
- **环境漂移的一锤定音对照法**:Node 24→25 升级致 vitest jsdom
  localStorage 破损(split-pane 11 用例结构性红)——单跑定位+最小
  诊断件(临时 diag test 打印 proto)+`npx -p node@24` 版本对照
  三步定案;环境归因不清时禁改测试迎合。
