## 5. 方法论资产

1. **变异红证夹具敏感性**:M5(量测恒等变异)首轮逃逸——W1→W2 只变宽度
   而 y 维恒紧约束(k 由高度决定),fitViewport 输出对变异不敏感→恒绿。
   夹具设计必须保证**输出对变异点敏感**(两维中至少被测维为紧约束);
   逃逸后收紧=加强非放宽,须对全部 M 重验(终版 M5 检出 ②⑦⑧三处)。
2. **备案动机与修复兑现面错位时如实降级**:备案现象可能只在探针环境
   存在(真实 UI 路径不可达)——闭环时台账写「真值面=什么」,不沿用
   备案动机邀功;A-main 顺带锁住的真实路径(重挂载 mount fit)如实
   记为净收益。
3. **「无自激励」类不变量的非平凡锁法**(门一 W4):断言「回调后观察者
   未重注册」前必须先锚定**新值真的产生了重渲染**(改量测→fire→
   transform 变了),否则同值 bail 路径下断言恒真=假锁。
4. **一阶原因触发源设计**(票面裁决记录):候选修法(uiScale 进 deps)
   是二阶代理且带 effect 序陷阱;RO 观察 svg 布局盒以一阶原因(尺寸
   变化)为源,同源覆盖换档+resize+侧板,零 props 穿透——接缝类小票
   优先找一阶原因。
5. 控制台回显乱码三验法(node 读回 FFFD 计数)在提交信息场景同样适用
   ——存储层 UTF-8 与显示层 codepage 分离判定。
