# ADR-0016：闲时会话预裁决表

日期：2026-08-27 · 状态：已裁决——闲时会话线的常设规则（效力序：AGENTS.md > 本 ADR > idle 卡链）

## 背景

用户裁决「闲时连续开发+人工卡点提前决策」：无人值守会话不可追问，一切原需
人工的卡点预先固化为确定性规则。规则先以 idle 卡链草案形态运行一场完整
会话（条件授权 push 五条件全机检；网络失败按规则记录后停止、无重试循环），
随后升格为本 ADR（含一项修订：会话节奏上限取消）。idle 卡链原始草案=仓外
档案区 docs-2026-10-28/prompts/2026-08-27_idle-handoff-v1.md。

## 裁决（七条有效集）

| 原人工卡点 | 无人值守规则 |
| --- | --- |
| push 前问询 | **条件授权**，全满足则直接 push：①verify 真退出码 exit 0 ②含 e2e 面时 e2e 全绿 ③隔离一审与终审通过且审计证据存档 ④diff --stat 与单元范围相符 ⑤受锁触碰带 [locked-change] 且 locks 同步。任一不满足=本地 commit 即停（禁 force-push；网络失败=记录后停不重试循环） |
| BLOCKING 审计发现 | 凭书面先例+机器事实可当场处置→处置并引用出处；否则终止 |
| 测试/契约问题（改受锁面才能绿） | 立即终止，不做 [locked-change]（留给有人会话） |
| 返工 ≥2 次 | 终止 |
| 实现歧义（工单正文未覆盖） | 查先例（ADR→ROADMAP→工单正文→invariants→最新交接书）；无先例或互斥→终止 |
| 上下文 60% 边界 | 预告即收尾（交接书→终局三查→commit） |
| 会话节奏（2026-08-27 用户修订） | 上限取消——60% 边界与终止条件内可连续多单元；工单逐单提交纪律不变（每单独立 verify+隔离一审与终审+翻状态+commit） |

## 后果

- idle 卡链（idle-handoff-v*，仓外档案区 docs-2026-10-28/prompts/）继续
  作为操作载体：开工自检/环境纪律/终止动作序/交接书模板留在卡级；本表
  语义冲突时以本 ADR 为准（防版本传递漂移）。
- 闲时线遇三阶段流程单元时叠加 ADR-0017（主控裁决权同样受上表终止条件
  约束）。
