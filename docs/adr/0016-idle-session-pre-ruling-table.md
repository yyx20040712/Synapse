- 状态：已裁决——闲时会话线的常设规则（效力序：AGENTS.md > 本 ADR > idle 卡链；
  卡链仅作操作性载体，语义以本 ADR 为准，防版本传递漂移）
- 关联：idle-handoff-v1 §1（原始草案）/idle-handoff-v2 头注（节奏修订）/

## 背景

用户裁决「闲时连续开发+人工卡点提前决策」：无人值守会话不可追问，一切
原需人工的卡点预先固化为确定性规则。v1 §1 以卡级草案运行一场完整会话后，
用户批准升格为本 ADR（含一项修订：会话节奏上限取消）。

## 裁决（七条有效集）

| 原人工卡点 | 无人值守规则 |
| --- | --- |
| push 前问询 | **条件授权**，全满足则直接 push：①verify 真退出码 exit 0 ②含 e2e 面时 e2e 全绿 ③双门终审 PASS 且存档 scripts/audits/ ④diff --stat 与单元范围相符 ⑤受锁触碰带 [locked-change] 且 locks 同步。任一不满足=本地 commit 即停（禁 force-push；网络失败=记录后停不重试循环） |
| BLOCKING 审计发现 | 凭书面先例+机器事实可当场处置→处置并引用出处；否则终止 |
| 测试/契约问题（改受锁面才能绿） | 立即终止，不做 [locked-change]（留给有人会话） |
| 回炉 ≥2 次 | 终止 |
| 实现歧义（票面未覆盖） | 查先例（ADR→ROADMAP 裁决节→票面→invariants→最新交接书）；无先例或互斥→终止 |
| 上下文 60% 边界 | 预告即收尾（交接书→终局三查→commit） |
| 会话节奏（**2026-08-27 用户修订**） | ~~恰好一个逻辑单元~~ **上限取消**——60% 边界与终止条件内可连续多单元；工单逐单提交纪律不变（每单独立 verify+双门+翻状态+commit） |

## 后果

- 闲时开工卡链（idle-handoff-v*）继续作为操作载体：开工自检/环境纪律/
  终止动作序/交接书模板留在卡级；本表语义冲突时以本 ADR 为准。
- 闲时线遇三屋模式单元时叠加 ADR-0017（主控裁决权同样受上表终止条件约束）。
