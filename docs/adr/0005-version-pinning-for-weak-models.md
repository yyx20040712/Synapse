# ADR-0005：版本钉选向训练数据倾斜（版本以 package.json 为单源）

日期：2026-08-21 · 状态：已接受

## 背景

弱模型对依赖库 API 的幻觉率与训练数据量强相关。钉选「社区示例最多」的版本可显著降低填充错误率，配合 docs/DEVELOPMENT.md「本仓库惯用法速查」双保险。

## 候选

- 精确固定版本（无 `^` 范围）：训练数据最多的版本，API 行为可预测。
- 范围版本/追新：示例少、行为漂移，弱模型幻觉面大。

## 裁决

全部依赖精确固定版本、无 `^` 范围（供应链纪律=docs/security.md 第 5 节）。版本以 `package.json` 为唯一真相源；下表仅记录选型理由，升级时同步：

| 依赖 | 选型 | 不用 |
| --- | --- | --- |
| pdfjs-dist | 4.10.38（精确） | v5/v6（API 与 CSS 变量体系新、示例少） |
| React | 18.3.1（精确） | 19（生态示例尚未跟上） |
| Electron | 44.4.3（精确；升级沿革见 ADR-0006） | 追新线（行为可预测优先） |
| zod | 4.6.7（精确；3→4 安全升级见 ADR-0031） | 停留旧线 |
| 其余 | 社区主流线 | 小众/过新库 |

## 后果

- 升级一律走 ADR + [dep-change]，升级后全量 `npm run verify` + e2e。
- Dependabot 只用于安全补丁（CVE 触发时评估最小升级）。
- 本表曾出现表值滞后于实际版本的漂移——「package.json 为唯一真相源、本表仅记理由」的防御句有效；表值随每次依赖 ADR 同步更新。
