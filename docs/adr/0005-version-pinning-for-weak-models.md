# AD-5：版本钉选向训练数据倾斜（弱模型适配）

日期：2026-08-21 · 状态：已接受

## 决策

| 依赖 | 选型 | 不用 |
| --- | --- | --- |
| pdfjs-dist | 4.10.38（精确） | v5/v6（API 与 CSS 变量体系新、示例少） |
| React | 18.3 | 19（生态示例尚未跟上） |
| Electron | ^33 | 更新线（行为可预测优先） |
| zod | ^3.24 | v4 |
| 其余 | 社区主流线 | 小众/过新库 |

## 理由

弱模型对版本 API 的幻觉率与训练数据量强相关；钉"社区示例最多"的版本可显著降低填充错误率（K5）。配合 `docs/DEVELOPMENT.md` 惯用法速查双保险。

## 维护

升级一律走 ADR + [dep-change]，升级后全量 `npm run verify` + e2e。Dependabot 只用于安全补丁（CVE 触发时评估最小升级）。
