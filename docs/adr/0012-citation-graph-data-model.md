# ADR-0012：引文图数据模型（自动引文网络图维持不做）

日期：2026-08-25 · 状态：已裁决——暂不实现，条件复审

关联：ADR-0011（语料接口）；ROADMAP 候选池本条目。

## 背景

「跨文献引用关系」在 ROADMAP 候选池只是一句词条目（RIS/EndNote、引用网络等同类），无数据模型设计。2026-08-25 裁决时清查确认：当时 7 张业务表无 paper 间引用关系承载（现行库已演进为 22 表+4 FTS 虚表——src/main/db/migrations/026_baseline.sql）；enrich providers 有引用数据获取的代码预留（src/main/services/enrich/providers/crossref.ts:23「不做：分页/游标/引用关系」、openalex.ts:21「不做：作者实体/机构/引用网络」）；网络图可视化已裁决不做（线性列表/标签/集合/md 语料承载）。

## 候选

- 立项实现引用关系数据模型：新引用表+迁移+FTS 联动+导入/去重语义（同一文献多来源 id 映射）+UI 面，是一个完整专项的量级。
- 暂不实现：预留点保留，条件复审。

## 裁决

暂不实现。量化依据：

1. **无显式消费者**：用户一手需求中无引用关系条目；「分析/串联领域」的载体在既有裁决下由 md 语料（ADR-0011）+标签/集合线性结构承担——AI 蓝图的领域梳理模式消费的是语料而非引用图。
2. **成本真实且不小**：裁决时点 001 迁移已冻结（只能追加；现行迁移链已压缩为 026 基线单件——ADR-0030），上述完整专项量级的成本没有对应收益。
3. **预留零成本**：providers 预留点保留不动（死代码红线不触发——它们是增强域的既有限制分支，非孤儿）。

复审条件（暂不实现不构成永久否决）——任一成立即重评立项：

- AI 链条领域梳理落地后，「按引用聚类/被引排序」成为用户真实工作流诉求；
- md 语料的消费实践中，AI 侧明确需要引用关系字段（届时优先考虑：导出时经 enrich 缓存拼入 manifest 元信息，而非应用内建表——接口侧扩展成本低一个量级）。

## 后果

- ROADMAP 候选池本条目状态=「已裁决暂不实现（ADR-0012），条件复审」。
- 不新增任何迁移/UI；providers 预留点维持现状。
- lineage 图（ADR-0014）落地不改变本裁决：lineage 边是人工策展产物，与自动引文边是两个对象，不复用表。
