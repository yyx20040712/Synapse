# ADR-0012：跨文献引用关系数据模型——暂不做（占位裁决）

- 日期：2026-08-25
- 状态：已裁决——暂不实现；enrich providers 既有预留点保留；条件复审
- 关联：ROADMAP P8+ 候选池；B1 报告 §3（crossref.ts:21 / openalex.ts:19 预留）；
  负面清单「知识图谱」边界声明；ADR-0011（语料接口）

## 背景

「跨文献引用关系」在 P8+ 候选池为一句词条目（RIS/EndNote、引用网络等同类），
无数据模型设计。B1 清点确认：现有 7 张表无 paper 间引用关系承载；enrich
providers 有引用数据获取的代码预留；负面清单已裁决不做网络图可视化
（线性列表/标签/集合/md 语料承载）。

## 裁决：暂不实现

量化依据：

1. **无显式消费者**：用户一手需求（WPS 范式六组+北极星愿景）中无引用关系
   条目；「分析/串联领域」的载体在既有裁决下由 md 语料（ADR-0011）+
   标签/集合线性结构承担——AI 蓝图的领域梳理模式消费的是语料而非引用图。
2. **成本真实且不小**：001 迁移已冻结（只能追加）——新引用表+迁移+FTS 联动
   +导入/去重语义（同一文献多来源 id 映射）+UI 面，是一个完整战役的量级。
3. **预留零成本**：providers 预留点保留不动（死代码红线不触发——它们是
   增强域的既有限制分支，非孤儿）。

## 复审条件（占位不构成永久否决）

任一成立即重评立项：

- AI 链条领域梳理落地后，「按引用聚类/被引排序」成为用户真实工作流诉求；
- md 语料的消费实践中，AI 侧明确需要引用关系字段（届时优先考虑：导出时
  经 enrich 缓存拼入 manifest 元信息，而非应用内建表——接口侧扩展成本低一个量级）。

## 后果

- ROADMAP P8+ 池本条目状态=「占位已裁决（ADR-0012），条件复审」。
- 不新增任何迁移/UI；providers 预留点维持现状。
