# ADR-0008：notes.store 五模块级结构维持分布式状态机（不坍缩为显式状态机）

- 日期：2026-08-23（UBS 战役批四 D1 裁决）
- 状态：已裁决——不重构（维持现状）
- 关联：docs/invariants.md INV-04；docs/reports/2026-08-23_defect-campaign.md U2；
  docs/reports/2026-08-23_ubs-sweep.md §D1；docs/reports/2026-08-23_ubs-campaign.md §3

## 背景

notes.store 有五个模块级编辑元数据结构：`pendingEdit`（未保存编辑集合）、
`editSeq`（编辑序号）、`touchedFields`（已触碰字段）、`loadedOnce`（首载标记）、
`lastEditedAt`（最近编辑时刻）。UBS 战役评估将其坍缩为单一显式状态机
（状态×事件→迁移表）的可行性。

## 裁决：不坍缩

### 量化依据

1. **行为已锁定**：五结构支撑的语义由 13 条锁定用例（U2 十条 + UBS A4 三条）+
   D2 固定种子性质攻击（12 种子×24 步内容安全/savedAt 单调不变量）+ 五轮
   deepseek 审计（U2 战役）覆盖。坍缩=全部跨格序列重推导再验证。
2. **各结构生命周期正交**：pendingEdit 由 edit 打点/save 成功（序号守卫）清；
   touchedFields 由 edit 打点/save 成功清/整版清/合并保留；editSeq 单调自增；
   loadedOnce 一次性打点；lastEditedAt 仅取存在性。五个维度不是同一状态机的
   五个态——是五个正交坐标，其组合才是态空间。坍缩成单状态机需要把
   2×2×2×2×2 量级的组合显式枚举（多数组合不可达），表反而比五个布尔更难审。
3. **重构成本 > 概念收益**：U2 教训（18 格单格全过、跨格序列丢稿由 deepseek
   第五轮拦截）证明该模块的验证成本主要在跨格序列枚举，不在结构表达。重构后
   需要等量的再审计（五轮量级），概念可读性收益边际。
4. **镜像已收口**：A4 引入的 `NoteDraft.pending` 是 pendingEdit 的响应式镜像
   （四个同步点显式对偶），显示诚实性问题已在不触碰五结构的前提下解决。

### 重审触发线（何时重新评估）

- 五结构出现**第二次**生命周期缺陷（宪法「同类缺陷二次触发即重构」）；
- 需要第六个编辑元数据维度（正交坐标继续膨胀，可读性拐点）；
- 多文献并发编辑（v2 若引入）使组合空间真正需要显式枚举。

## 后果

- 维持现状；新增编辑元数据须沿用「模块级 Map/Set + NoteDraft 镜像同步点」形状。
- 本 ADR 与 D2 性质测试（ADR-0009）共同构成该模块的行为防线。
