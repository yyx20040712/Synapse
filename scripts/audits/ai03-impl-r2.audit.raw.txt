**问题 A：`questionOrder` 的稳定性/边界**

`questionOrder`:
```ts
function questionOrder(q: string): number {
  return q === 'divergence' ? 99 : Number(q.replace('Q', ''))
}
```
如果 `q` 不是 'divergence' 且不以 Q 开头，比如 `q = 'q1'`（小写），`Number('q1'.replace('Q',''))` = `Number('q1')` = NaN。NaN 在排序比较中总是返回 false？`(NaN - NaN)` = NaN，比较 `NaN !== 0` 为 true，所以会落到 `a.createdAt === b.createdAt ? ...`。但 `qDelta = NaN - NaN` 是 NaN，`if (qDelta !== 0)` 为 true，返回 `NaN`，Array.sort 期待数字，但 NaN 会被当作 0？实际上 JS sort 的 comparator 返回 NaN 时行为是不确定的（通常当作 0）。这可能导致不稳定。但根据类型系统，`AiNoteQuestion` 应该只有 'Q1'...'Q7' 或 'divergence'。所以输入受控。不值得 WARN。但也许可以 NIT：建议对 questionOrder 使用 hasOwnProperty 或显式映射。

**问题 B：`advance` 中等待 `startPaper` 的异步性**

`advance` 是 async：
```ts
async function advance(s: ActiveSession): Promise<void> {
  const next = s.queue.shift()
  if (next !== undefined) {
    await startPaper(s, next)
    return
  }
  // finalizing...
```
