## 3. 复算配方（完整公式+中间值——本版与数字自洽）

1. 读 `real3882-{p2,p7}-dual.json` 的 `anchors[form==='bottom']`;
2. A=rectsA（DOM 链归一块）/B=rectsB（项几何链归一块）,area(r)=w×h;
   Atot=Σ area(A), Btot=Σ area(B);
3. 整窗交集 Σ∩=Σ_{ra∈A} Σ_{rb∈B} inter(ra,rb),inter=矩形面积交;
4. **缺集主口径=对称差 A△B=Atot+Btot−2·Σ∩**（p2=0.0365/p7=0.0361,
   与 §1 边栏+非边栏合计 0.0365 自洽）;并列口径=并集缺 A∪B−∩=
   Atot+Btot−Σ∩（p2=0.0847/p7=0.0944）;
5. 边栏块=h>0.4 的块（两链各恰 1 块）;边栏缺集贡献（对称差口径）=
   sbAreaSum−2·sbInter=0.0039（sbAreaSum=B 边栏面积+A 边栏面积=
   0.0074+0.0113=0.0186,sbInter=0.0074）;非边栏=总缺集−边栏贡献;
6. 贪心配对（仅供形态分类,不入占比计算）：全对 IoU 降序迭代,取
   IoU≥0.01 且双方未被占者对;
7. cmp.area.iou 与本文贪心 IoU 的关系：cmp 为**按序对 Σ∩/Σ∪**（块对
   按下标序强配,错对块交集计 0 但面积全计并集——cmp.blocks 数组长度
   11/14、pairedA=10/12、countA/countB=12/15 三者不一致,按序强配在
   分块错位时系统性低估;块 [8]（0 基）IoU=0（dx=−0.4381 按序强配
   伪影,块 [9] IoU=0.1503 非零——「两个零块」表述失准已修正）,
   故 cmp.area.iou 0.4225 < 贪心重构 0.5687;方向性低估论证成立,
   幅度以本文重构值为准。
