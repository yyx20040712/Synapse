- `file: ''` 时：规则 1 `existsSync(join(root, ''))` = `existsSync(root)` = true → 过；规则 3/4b `statSync(root).isDirectory()` → `continue` 跳过；规则 0 只查 id。**done 票一个空串即全规则免疫**——本票修的正是"file 指向无效路径平凡绿"这一类（redproof-a 直证的那类），修复实现却新开了同类的门。
- 同类残余：行首正则不匹配时（字段序漂移、`id :` 多空格、prettier 折行）`continue` **整票静默消失**，且无任何对账哨兵（如 `registry.match(/\bid: '/g).length !== tickets.length → exit 1`）。旧版至少在字段缺失时 `exit(1)`，新版把这类故障从"红"降级为"消失"——与本票"防静默脱检"的立法目的直接冲突。

修复成本极低（`*`→`+` 或显式空串检查 + 解析数对账），但它开在本关卡的防作弊语义核心上，判 B。
