## 1. 中风险：形态锁无法拦截"异形态同效果"回归（B/C 交叉）

### 1.1 间距负锚只锁了"单引号/裸数字"一种历史形态

测试正则：

```ts
/(padding|margin|gap)(Top|Bottom|Left|Right)?:\s*('[\d-]|[\d])/
```

放行 `marginLeft:'auto'` 与 `var(...)` 值的意图正确。但该正则存在可绕过面：

- **双引号字符串形态**：`padding: "0 4px"`、`paddingLeft: "6"`——首字符为 `"`，正则不匹配（模式只允许单引号后接数字，或裸数字开头）。
- **模板字符串/拼接形态**：`paddingLeft: \`${6}\``——不匹配。
- **kebab-case 对象键**（非 React 场景）：`'padding-left': 6`——不匹配，因为 `(Top|Bottom|Left|Right)?` 只吃驼峰后缀。

当前 diff 中 12 处迁移全部为单引号 `'0 4px'`/裸数字形态，锁对这些**原始回归形态**有效。但若未来回退者写成双引号，形态锁静默放行。

**降级因素**：这是防回退锁而非验收锁；真正验收由探针承担。且原代码历史形态即单引号，双引号回退属低概率变体。

### 1.2 弹层 z 类锁漏掉 `z-[50]`、`z-50!`、动态拼接等合法 Tailwind 形态

```ts
not.toMatch(/\bz-(10|20|40|50)\b/)
```

只锁裸 `z-50`。以下等价写法全部漏网：

- `z-[50]`（v4 任意值语法，完全合法）
- `z-50!`（important 后缀，`\b` 在 `50` 与 `!` 之间成立吗？`!` 是非单词字符，`50` 后跟 `!` 处有词边界，所以 **`z-50!` 会被捕获**，这点安全。但 `z-[50]` 因 `50` 后跟 `]`，`]` 是非单词字符——`50]` 之间也有词边界，`z-` 后不是数字所以不匹配。故 `z-[50]` 确实漏网。）
- `z-(--z-pop)` 被误改回 `z-(10)` 之类的 CSS 变量形态也不匹配（但 `z-(10)` 本身不是合法 Tailwind 变量简写，需配 `--z-10` 自定义变量才能编译）。

更本质的盲区：**该锁只锁类名字面形态，不锁"类→token→值"的消费链**。若有人把消费端改为 `z-[50]` 而 token 定义仍为 `--z-pop:50`，全部测试仍绿，视觉也仍为 50——但语义命名资产被绕过。

**降级因素**：值面锁（TOKENS 数组）锁住了 token 定义值与 :root 的一致性；变异红证②证明该锁对 token 值漂移有鉴别力。缺陷在于**没有一条断言锁"弹层消费端必须引用 --z-* 变量"**——在场锚只覆盖了 4 个 class 名（且为子串锚），未覆盖全部 12 个消费位的类名与 token 的关联。

### 1.3 duration 值面计数锁漏 `0.30s`/`300ms` 等异形态

21 三元组的 `countLiteral` 按字面子串统计。`0.3s` 的定义行 `--dur-flow: 0.3s` 出现 1 次；若有人把某消费端写成 `300ms` 或 `0.30s`，字面 `0.3s` 计数不变，测试绿而视觉不变（值仍等价）——但语义载体被绕过。若写成 `0.35s`，则计数变 2 会红（若恰在 theme.css 内）或变 1（若恰在原 0 处文件）。所以锁对**数值漂移**有效，对**形态变异**无效。

**降级因素**：机械迁移票面锁的是"值不变"，`300ms` 与 `0.3s` 计算值等价，零视觉差不被破坏；这是语义纯度盲区而非视觉验收盲区。

## 2. 中低风险：在场锚断言形态（B）

三个在场锚均为精确子串断言：

- `toContain('className="pt-2"')`——若 Tailwind 类与其它类合并，或 className 顺序调整，即使视觉效果不变也红。实现者已在自裁②声明"可接受脆性"。**同意可接受**，因这些是防假绿锚不是产品行为锁。
- `toContain('className="gap-0.75 px-0.75"')`——顺序敏感。当前实现恰好为此顺序，与 diff 一致。
- `toContain('className="pl-1"')`——该断言**可能误伤**：`pl-1` 是 `pl-1.5`/`pl-10` 等的前缀子串吗？`toContain('className="pl-1"')` 要求闭合引号，所以 `className="pl-1.5"` 不匹配（`"` 位置不对）。安全。但 `className="pl-1 pl-1.5"` 这类复合会匹配——无实际风险。

**真正的覆盖缺口**：12 处迁移只锚了 3 个文件中的 6 个类。LineageSideAiNotes/ManualNote/Panel 三件的 `pl-1.5` 锚在侧板 describe 内确实存在（第三个 it 覆盖了三文件各含 `pl-1.5`），所以 12 处实际全覆盖。核对无误。

### 3.2 `z-(--z-pop)` 的编译与层叠等价性

- Tailwind v4 函数简写生成的 utilities 类与旧 `z-50` 同属 utilities 层、同特异性（单类）。同一元素不会同时挂两个 z 类（9 文件 12 处各自唯一），因此层叠顺序无关。
- 类名字面含括号：CSS 选择器转义仅影响 CSS 侧，HTML class 属性无需转义，浏览器按字面匹配。编译产物若为 `.z-\(--z-pop\)`，与 DOM 的 `class="z-(--z-pop)"` 精确匹配。风险在 Tailwind 编译器对 `--z-*` 变量的解析成功与否——verify 已过、构建 exit=0，说明编译面无错误。
- **特异性等价结论成立**。但注意：若未来 Tailwind 升级改变该简写的编译行为（如要求 `--z-pop` 必须为裸数字可静态内联而回退），此形态可能静默失效——这是工具链依赖风险，非本次验收风险。

### 3.3 悬停/选中/禁用特异性

本次迁移不涉及任何 hover/selected/disabled 规则面的属性竞争：

- duration 迁移全部在 transition 声明内，不改变选择器特异性；
- z-index 迁移全部在静态类/元素选择器上；
- 间距迁移元素无伪类状态规则作用于 padding/gap。

有 B1 头注"静态+hover 同层"教训，但迁移面未触碰任何悬停态属性，无同层改写问题。

## 5. 接缝与后续单（E）

### 5.1 批二预留

`--dur-*`/`--z-*` 命名空间与 `--fs-*` 无冲突；token 插入区位于 `--radius-l` 后、`--font-display` 前，批二扩展 `--fs-*` 可自然延续。**预留正确**。

### 5.2 INV 延后登记

票面写明"同族 token 单源面一并登记"。批一不登记 INV 意味着"design token 单源"不变量在批一与批二之间**存在空窗期**——若批二延后或取消，批一的 token 资产将无 INV 保护。但这是主控在档决策（§3 预裁③），且视觉零差探针已承担当下验收。**合理性成立，风险记档即可**。

### 5.3 SelectionToolbar 头注语义准确性

"层叠序最顶"指 SelectionLayer 页内比较域内最顶；`z-(--z-float)=10` 在弹层域内实际低于 `--z-pop:50`。page-layer-z.ts:17 头注更新后准确表述为"菜单/编辑器/工具条在页盒兄弟位，天然高于页内域诸层"——此措辞将比较域限定在页内，**与 `--z-float` 同时被 app-header 使用的现实不冲突**（app-header 在窗口级，与页内弹层不同比较域）。语义准确。

## 6. 主控亲验项的攻击尝试
