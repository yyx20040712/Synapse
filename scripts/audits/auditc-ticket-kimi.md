## 1. 战役定义

**目标面一句话**：把「await/事件窗口内状态被另一方改写」这一时间维度缺陷族，从逐案打补丁（INV-29 增补 F-ARCH1、INV-34 增补 F-R2 量纲、INV-18 增补 deferOutcome——全是事后补登记）升级为一次系统性清点+分层锚定：全仓枚举时序候选面，实锤立案修复、翻案回归锁、弱锚补强、不可复现备案，产出一张「时序面全图」，使后续 INV 增补从被动响应变为主动对照。

**不在范围（负面条款——与 AUDIT-B/D/E 的边界）**：

| 面 | 归属 | 边界判据 |
| --- | --- | --- |
| 功能对偶矩阵 6 对未验（双击最大化×滚动记账等） | AUDIT-B | 属「状态组合几何面」非时间窗口机制；交集项（关闭拦截弹框×最小化涉 INV-22 状态机）若排查发现时序根因则转入本场，否则留 B |
| 数据正确性（迁移一致性/FTS 触发器同步） | AUDIT-D | 非时序面；但「文件与 DB 读写并发」组（INV-17/18/26/35）的**时序维度**归本场 |
| 性能指标 | AUDIT-E | 压力序列跑在本场只是复刻手法，不以性能为验收 |
| 环境非确定性（D:\nodejs v25 漂移/负载 flake/R3-RDRSET 间歇红） | 场首 e2e 信噪比双件+DevOps | 判据=**应用内时序窗口是否存在**；纯环境噪声不算竞态，不在场内 |

## 3. 方法论（四手法+适用条件+选型矩阵）

**M1 静态代码链分析（只读全枚举）**
- 先例：F-L3 静态面（GLM5.3 只读子代理 1.46M tok 全枚举 renderer scrollTop 写入点逐一读链，结论「保存链零滚动写入路径」）。
- 适用：①写入点集合 grep 可收敛；②需要「路径存在/不存在」级判定；③产出直接喂票面（关键裁决链）。
- 纪律：必须给全集清单+逐条读链结论，禁抽样；结论三态（存在/不存在/不确定），不确定即转 M3/M4，禁含糊闭环。

**M2 注入复刻（受锁先红注入形态）**
- 先例：p7a-red1（外部占用注入复刻剪贴板竞态先红）；F-A4/F-L1-C（注入碎裂 rects 7 块/碰撞源 5 标签）。
- 适用：①竞态窗口已知但概率低（扫描连开/顺序敏感）——注入把概率窗口变确定性窗口；②需「先红」满足 TDD 纪律。
- 纪律：注入只经探针/夹具侧，**禁改实现码**；产物落盘 scripts/audits/；注入未命中→只降级「当前注入形态未复现」，转 M4 对照，**不得宣布缺陷不存在**。

**M3 压力序列跑（时序压力+判据底座）**
- 先例：e2e 三连跑 29/29×3（F-R2e 证伪面）；F-R1 探针 17/17 两轮稳定；P7-A 修复后连跑 3 次全绿。
- 适用：①用户路径=高频重复操作；②需要统计置信——「同用例 2 次非确定失败=立案」通则（2026-09-02 入册）即判据底座。
- 纪律：失败必录指纹（差值/同值/序列位置）；flake 与真竞态的区分=指纹同值性（F-R2e「同值复现 3.45px」即指纹锚）。

**M4 真机探针分段采样（f-l2-probe 范式）**
- 先例：f-l2-probe.mjs（真实库副本复刻+fitViewport zoom 污染实证）；f-l3-probe.mjs（双模式对照三模式全零漂移）；f-l2-precheck.mjs（前置实测三问先行，防方案建立在错误假设上）。
- 适用：①现象只在真浏览器/真数据形态可达（jsdom 结构性不可达——F-ARCH4-M1 教训）；②需区分「工具面假象 vs 应用缺陷」（F-L3 范式：Playwright scrollIntoView 工具面 vs CDP 真鼠标直发）。
- 纪律：探针前 ABI 断言（探针前 use electron、verify 前 use node——v16 双坑入档）；**固定 waitForTimeout 禁新增**（INV-44 备案教训，一律条件轮询）；产物=json 断言+截图落盘。

**选型矩阵**：「是否存在路径」问 M1；「能否确定性复现」问 M2；「频率/置信」问 M3；「真机形态/工具面区分」问 M4。**排查票标配=M1+M4 双路**（F-L3 双重证据范式：单路证据不得宣布闭环）。

## 4. 首波范围（三张票）

终裁输入四项的处置映射：**F-L3 已排查闭环**（2026-09-02 不可复现，双重证据在档）→不另开票；其范式固化为本场 M1/M4 标配，且「保存链零滚动写入」结论纳入 C-3 扫描的态空间基线。余项拆三票：

### 票 C-1：F-R3 pdfjs stream pump 竞态排查票（排查票，不修）

- **面**：PdfDocProvider loadingTask.destroy() 与 stream 泵竞态；扫描式连开 openPaper 触发 pageerror。
- **边界**：只排查+取证，不改实现；同读 INV-30 取消队列（E2）与 CorpusExtractor 生命周期（E3）防结论误伤既有锚。
- **手法链**：M1（loadingTask/destroy/render cancel 调用链全枚举）→M2（注入快速连开序列确定性复刻）→M3（连开 N 次，pageerror 计数+指纹）→M4（真实库副本探针，分段采样 tab 生命周期各点 pdfjs 内部态）。
- **产出**：实锤→修票票面素材三件（根因/修法候选/INV 增补草案——候选宿主=INV-30 增补或新 INV「pdfjs 文档生命周期销毁序」）；不可复现→F-L3 式双重证据备案+挂 2 次立案线。
- **依赖**：无（reader pdfjs 域独立文件面）。

### 票 C-2：弱锚时序三条目锚定补强票（小同形合票）

- **三条目**：①INV-42 N6 选择模式点击 rect 零副作用**真机直测**（当前=三层推断）；②F-ARCH4-M1 root.contains 真浏览器可达性（e2e 反向选区用例，台账原标「低优先」，本场搭车收口）；③INV-44 备案② f-l4-verify.mjs 固定 waitForTimeout(900/1200) **轮询化**（CI 慢机误报防线）。
- **合票理由**：同形（均为「已锚定的锚点补直测」），§4.5 小同形批量条款一次派发；①②涉受锁面（e2e/tests 新增 [locked-change]），③探针脚本非受锁。
- **边界**：只补锚不改行为；①②直测若发现推断不成立→停手登记、修复另开票（见 §8 R5）。
- **依赖**：与 C-1 文件面不交叉（C-1=PdfDocProvider；C-2=AnnotationLayer 消费面/anchor e2e/lineage 探针），可并行派发；ABI 争用统一 verify 兜底（v16 F-V1/F-LG 并行先例）。

### 票 C-3：时序面静态全枚举扫描票（只读扫描，产出喂二波）

- **面**：以「await 窗口+写方向」为纲全仓扫描三组——①全部 store 的 async 写路径（save/undo/delete/edit）在 await 窗口内的状态读写（A 组盲区，**A3 悬置写立案依据由此产出**）；②IPC invoke 往返窗口内 renderer 侧状态消费（含 C1 窄窗接受判据复核）；③事件桥载荷「发出时快照 vs 消费时现态」全链（LG-08 同族扫描）。
- **手法**：纯 M1；附带消化架构批 W7 欠账——PageColumn/SelectionLayer 组件级态空间表补齐。
- **产出**：态空间缺口清单（每 async 写路径给「守卫在场/缺席/不确定」三态表）；每个「守卫缺席」条目附后果推演（用户路径可达性×后果级别）；≥B 级候选入二波修票，全 W/N 级→二波不启动。
- **依赖**：无；与 C-1/C-2 互不阻塞。

## 5. 分波次编排与停点判据

**首波（本场）**：C-1+C-2+C-3。停点判据=三票全闭环——**排查票以「证据双路齐全+结论备案」为闭环，非以修复为闭环**；预算纪律=单票回炉 ≤2 轮，整场消耗触 40% LOOP 预算即停，未竟面转下场首波续接（不硬撑）。

**二波（条件启动）**：启动条件=C-1 实锤 ∨ C-3 产出 ≥1 个 B 级候选 ∨ F3 再现达 2 次立案线。内容=修票（F-R3 修复 / A3 悬置写应用层守卫 / C-3 产出候选）+W-G1 band resolve 竞态定位。停点判据=修票全闭环+INV 增补入册；C-3 全 W/N 级则二波整体不启动，直接三波。

**三波（常态化）**：战役制转值守制——①「2 次立案线」通则即被动值守；②D4/D5 等低优先未排查面转遗留池，随相邻域改动搭车；③本场产出的「时序面全图」落 docs/（或 INV 册附录），后续新增 async 写路径工单须对照全图自查（工单模板文化层条款候选）。

**裁剪纪律**：首波即触顶时**裁 C-3 不裁 C-1/C-2**（C-3 可整票顺延，其产出是二波输入而非用户可感修复）；C-1 若 M1 已给出确定结论，M2~M4 按需裁剪，不跑满四手法。

## 6. 验收条款（DoD）

**共性 DoD（全场六条）**：

1. 排查票闭环=**证据双路**（M1 静态+M4 动态，或 M2 注入+M3 压力）齐全且结论三态明确；单路证据宣布「不可复现」无效（F-L3 范式条款）。
2. 修复票（二波若产生）=TDD 红→绿→断言级变异红证；真机探针取证落盘 scripts/audits/（json 断言+截图）；变异还原用 cp 备份法（禁 git checkout 抹未提交实现）。
3. **新发现的跨模块时序不变量必须入 INV 册**（声明处+强制方式+锚定状态三栏齐全）——本场核心验收条款：**无 INV 增补的实锤修复视为未完成**。
4. 受锁面改动=[locked-change]+全量 verify（playwright esbuild 不查类型，tsc 关卡必跑）；计数类数字脚本实测后落笔（2026-09-02 新入册条款）。
5. verify 真退出码亲验+locks 即时同步+diff 范围无蔓延；ABI 双坑纪律。
6. 不可复现结论=**备案非关闭**：台账走「备案观察」态+挂 2 次立案线，用户真机再现即升级。

**票级 DoD**：

- **C-1**：M1 必做，M2~M4 按结论需要；结论落台账 F-R3 条目（实锤→票面素材三件；不可复现→双路证据 json 落盘+观察挂线）。
- **C-2**：①真机点击 rect 断言 json（三场景对照沿用 f-a3 形态）；②e2e 反向选区用例入受锁面——root.contains 防线「真浏览器可达」或「规范化先行拦截」的实证定性二者居一，必须有机器结论；③轮询化+无固定 waitForTimeout 残留（grep 判据）。
- **C-3**：全枚举清单+三态表落盘（scripts/audits/audit-c-scan.md）；态空间表两件入档；B 级候选逐条附后果推演，禁只列现象不给定级依据。
